# 暢銷小說角色劇情方法論：可直接用於大綱的研究摘要


## 結論先行

最實用的整合不是把「三幕」「角色弧」「反派」分開填，而是讓每一幕都改變同一個角色核心問題：**主角為了外在目標採取行動；反派／對抗力量以相反目標或價值阻斷；代價升高，迫使主角放棄舊信念，最後以新的內在選擇完成或失去外在目標。**Save the Cat! 擅長把這條線拆成 15 個節點；Story Grid 擅長用「核心價值、類型必備場景、每場景的價值變化」檢查它是否真的在推進。[2][3][4]

## 1. 角色塑造 × 三幕結構

| 段落 | 角色功能 | 最少要回答的問題 |
|---|---|---|
| 第一幕（約前 25%） | 顯示主角的舊常態、缺陷／錯誤信念與可見欲望；催化事件使舊策略失效，主角跨入新局面。 | 他現在想得到什麼？為何只會用這個有問題的方式追求？若不出發，會失去什麼？ |
| 第二幕（約中間 50%） | 主角反覆以「舊的自己」追目標；外在阻力與關係線讓代價升高。中段必安排一個不可逆的翻轉；低谷將欲望壓縮成必須選擇的危機。 | 每次嘗試後，局面哪個核心價值變好了或變壞了？反派如何讓主角的舊信念更站不住腳？ |
| 第三幕（約最後 25%） | 主角用已轉變的理解做主動選擇，在核心事件／高潮承擔代價，讓外在結果成為內在變化的證明。 | 他現在採取的行動，和第一幕的他有何根本差異？贏或輸各自證明什麼？ |

Story Grid 將三幕定為 Beginning Hook（前 25%）、Middle Build（中 50%）、Ending Payoff（後 25%）；每幕必有核心價值的正／負移動與關鍵必備場景，第三幕高潮通常是「Core Event」。[3]

## 2. 外在目標（Want）與內在目標／需求（Need）

- **外在目標：**可觀察、可成敗判定的追求，例如贏得比賽、救出家人、揭露兇手、取得職位。
- **內在需求：**主角為完成故事真正得學會的事，通常與錯誤信念、恐懼、羞恥、關係模式或道德選擇相連；它不必與外在目標一致。
- **設計準則：**讓外在追求一開始看似可用舊信念完成；中段後證明「想要的東西」不足、甚至有害；高潮中讓主角以新需求指引行動。

Story Grid 將 All Is Lost 視為從 want 轉向 need 的樞紐：原本的 object of desire 被摧毀或顯出不值得追求，主角才有條件發現真正解法。[6]

**檢核句：**「他想要 ___，因為他相信 ___；但他真正需要 ___；反派逼他在 ___ 與 ___ 間做不可兩全的選擇。」

## 3. 角色弧（Character Arc）設計

1. **起點：**寫下舊信念（不是抽象缺點），例如「只要服從規則就能保護家人」。
2. **壓力測試：**每一個主要阻力都要使舊信念暫時更有效、但長期代價更大；否則角色只是在遭遇事件，沒有弧線。
3. **低谷：**讓主角失去原目標或承認世界觀無法解釋現實；這不是單純慘，而是舊自我失效。
4. **轉變證據：**高潮不以台詞宣告成長；讓主角做出第一幕不可能做的、有代價的選擇。
5. **終局鏡像：**終局情境呼應開場，但主角的選擇／關係／價值位置不同。

Save the Cat! 將小說定位為「轉化」：開場與結局之間要能追蹤信念、缺陷或身分如何改變；其小說框架以 10 種故事類型、15 個節點與 Board 規劃系統串接情節、弧線與情感效果。[2]

## 4. 反派與主角的對稱性

「對稱」不等於同樣背景或能力，而是兩人對同一價值問題提出互斥答案：

- **同一賭注，不同答案：**兩人都在爭取安全、自由、愛、地位或正義，但採取相反原則。
- **直接對撞的目標：**反派的 object of desire 必須直接反對主角的目標，而非只是製造麻煩。[4]
- **互為壓力測試：**反派最有效的攻擊，是誘惑主角繼續相信舊信念，或以更極端方式實踐它。
- **最後一戰是價值選擇：**主角的勝負要回答「哪種價值／方法能承擔代價」，不只比誰拳頭大。

Story Grid 將衝突分為內在、人物間、超個人（環境／制度）三層；情境應突出本書最重要的層次。類型規約再把主角、反派、盟友等角色配置為能推高衝突的條件。[4]

## 5. 核心衝突／Core Motive（可作為 Cornerstone）

「Cornerstone／Core Motive」並非 Save the Cat! 或 Story Grid 的單一固定術語；以下是把兩者可驗證概念整合成的工作欄位。[推論][2][3][4]

| 欄位 | 一句定義 | 用途 |
|---|---|---|
| 核心價值 | 本書最會失去或贏得的人類價值光譜，例如生存↔死亡、愛↔恨、權力↔無力。 | 篩除不服務主線的支線。 |
| 核心動機 | 主角此刻必須追求外在目標的私密理由。 | 讓行動有個人性，不只任務。 |
| 錯誤信念 | 主角自認能保護自己的舊規則。 | 指定角色弧的起點。 |
| 對抗命題 | 反派／制度對同一價值提出的相反答案。 | 設計對稱反派與升級阻力。 |
| 危機選擇 | 兩個都有代價的選項，不能靠巧合脫身。 | 把主題轉成戲劇行動。 |

可填成一段：「在 ___（舞台）中，主角為了 ___（外在目貴）而行動，因為 ___（核心動機）；他相信 ___（錯誤信念），卻被反派以 ___（相反命題）逼到必須在 ___ 與 ___ 間選擇；結局要驗證 ___（核心價值／主題）。」

## 6. 案例研究：*The Hunger Games* 的角色—結構耦合

Save the Cat! 的小說 beat sheet 將 Katniss 的開場欲望明確放在「生存」與保護 Prim；催化事件是 Prim 被抽中後，她自願成為貢品。該分析把主題寫成：她必須超越「遵守 Capitol 規則以求生」，走向反抗其不義秩序。[5]

- **外在目標：**在 Hunger Games 中生存／取勝。
- **核心動機：**保護妹妹與家人。
- **舊信念：**在系統規則內求生是唯一可行策略。
- **對稱對抗：**Capitol 將人視為可被操控、互相殘殺的棋子；Katniss 的路徑逐步拒絕這個定義。
- **B Story 的功能：**Peeta 線不是裝飾性戀愛；在該分析中，他提出「不只是棋子」的命題，讓 Katniss 的生存邏輯受到情感與道德壓力。[5]

**可複用的做法：**替每條 B Story 寫一句「它教會主角、而主線暫時無法教會他的真相是 ___」。若刪掉 B Story 後主角的信念仍可同樣轉變，這條線尚未真正接上角色弧。

## 7. Save the Cat! 與 Story Grid 的分工用法

| 需求 | 優先用法 | 產出 |
|---|---|---|
| 快速搭骨架 | Save the Cat! 15 beats | 一頁節點表：催化、進二幕、中點、All Is Lost、結局鏡像。 |
| 確保角色變化沒有斷 | Save the Cat! 的轉化線 + Story Grid 的 want→need | 每節點標示：主角相信什麼、採取什麼策略、失去什麼、學到什麼。 |
| 防止中段鬆散 | Story Grid 的場景價值變化與 Five Commandments | 每場填「起始價值→結束價值」；沒有改變就合併、刪除或重寫。 |
| 防止寫出不像該類型的書 | Story Grid 類型的 obligatory scenes / conventions | 依主類型列出必備場景與角色功能，先滿足讀者承諾，再求新意。 |
| 校準反派 | Story Grid 的對立欲望＋三層衝突 | 寫出反派欲望、主角欲望、直接衝突點，以及制度／環境如何加壓。 |

## 可直接貼進角色卡的 10 題

1. 主角最具體的外在目標是？
2. 他為何「現在」非做不可？
3. 他以什麼錯誤信念追求它？
4. 這個信念在第一幕曾如何保護他？
5. 反派要什麼，為何必然與他衝突？
6. B Story／盟友揭露哪個相反真相？
7. 中點後，什麼代價讓舊策略失靈？
8. All Is Lost 時，主角失去的是目標、身分、關係，還是自我敘事？
9. 高潮的不可兩全選擇是？
10. 結局中，哪個可見行動證明他已變（或拒絕變）？
