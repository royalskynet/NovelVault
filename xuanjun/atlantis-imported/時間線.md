# 地球時間線（共享宇宙主時間線）

涵蓋三作品共用的歷史節點：玄君書、亞特蘭提斯、黑暗命運IF 皆以此為基線。
darkfate 的 IF 分支點在本表用 ⚡ 標示。

## 史前 ~ 西元前

### ~13,000 BCE 諸神時代
- 人神共存。人類魔法文明達巔峰。
- 諸神觀察人類，亦被人類觀察。
- [[玄君七章秘經]] 體系雛形誕生。

### ~12,000 BCE 諸神離去
- 諸神集體離開地球（原因為禁忌）。
- 「罪人」被封印至[[玄君七章秘經#門|門]]另一邊。
- 「門外之物」概念被創造，但未實際運作至「終極秩序」階段。

### ~11,500 BCE 亞特蘭提斯崛起
- 大西洋中央的亞特蘭提斯文明興起。
- 與[[四族科技樹|北歐神族]] 簽署最初盟約。
- 與[[四族科技樹|蜥蜴人]] 為長期世仇。

### ~10,500 BCE 大災變 / 亞特蘭提斯沉沒
- 大規模災難（地磁反轉 + 「門」事件副作用）。
- 亞特蘭提斯本島沉海。
- 遺民四散至埃及、馬雅、印度、巴比倫、東亞。
- 阿祀那族雛形於東亞建立。

### ~10,000–4,000 BCE 史前文明潛伏期
- 北歐神族與蜥蜴人各自在地球小規模介入。
- 各古文明（蘇美、古埃及、商、印度河）皆有「天降使者」傳說。

### ~3,000 BCE 蘇美—阿卡德接觸
- 蘇美神話中的「Anunnaki」= 北歐神族 + 部分小灰人混淆紀錄。

### ~1,500 BCE 摩西時代
- 出埃及記中的「火柱」「分海」為北歐神族技術干預。
- 「十誡」石板部分技術源自北歐神族。

### ~1,000 BCE 所羅門時代
- 所羅門王「鎮魂瓶」收容早期蜥蜴人個體。
- 阿祀那族五系建制完成。
- [[玄君七章秘經]] 全本最後一次完整出現於世。

### ~500 BCE 軸心時代
- 釋迦、孔子、老子、蘇格拉底、波斯先知同時出現——疑為某次「集體啟示」事件。
- 北歐神族首次集體撤離地表，轉為長期觀察。

### ~0 CE 耶穌時代
- 神蹟為北歐神族 + 少量小灰人技術。
- 早期教會建立——黑桌體系雛形。

## 中世紀

### ~700 CE 伊斯蘭興起
- 古蘭經部分啟示來源不明（爭議）。
- 中東神秘主義（蘇菲派、Ibadi）開始接觸蜥蜴人。

### ~1100 CE 聖殿騎士團
- 騎士團於耶路撒冷挖掘聖殿山，發現[[玄君七章秘經]] 殘篇 + 蜥蜴人遺物。
- 騎士團後成為黑桌核心。

### ~1300 CE 騎士團解散
- 法王腓力四世清算騎士團——表面動機是財富，實際是奪取秘經殘篇。
- 殘篇分流至梵蒂岡 + 蘇格蘭。

### ~1500 CE 大航海與秘經外流
- 殘篇隨大航海散落新大陸。
- 馬雅、印加、中美洲遺址被歐洲人「發現」（實為奪取）。

### ~1600 CE 啟蒙運動萌芽
- 知識體系世俗化——秘經研究被科學主義邊緣化。
- **真正的秘經研究轉入地下**——共濟會、玫瑰十字會、煉金術士。

## 近代

### 1776 美國建國 + 共濟會
- 美國憲法草擬者多為共濟會員。
- 共濟會傳承部分秘經殘篇——後成為 DSI 雛形。

### 1850s 達爾文 + 科學主義
- 主流學界正式將「神秘學」打入偽科學。
- 影子層獲益：研究反而能徹底秘密化。

### 1888 倫敦黃金黎明
- 黃金黎明會吸引大量秘經殘篇研究者。
- Aleister Crowley 在此期間接觸到部分蜥蜴人。

### 1908 通古斯事件
- 表面：隕石。
- 實際：北歐神族武器試射（針對某個西伯利亞蜥蜴人據點）。
- Тень（俄方影子）的起源事件之一。

### 1917 俄國革命
- 列寧後期接觸過小灰人（未證實）。
- 蘇聯秘密研究 UAP 自此啟動。

### 1920s 納粹興起
- 希特勒入會的圖勒協會持有秘經殘篇。
- 黨衛軍 SS 設立特殊單位研究秘經與外星接觸。

### 1933–45 納粹秘密計劃
- **Die Glocke**（鐘）計劃 = 北歐神族技術逆向工程。
- **Vril** 計劃 = 與小灰人接觸嘗試。
- **分佈式主機計劃**：[[沈定]] 於 1943 年「啟動」。

### 1945.04 納粹瓦解
- 部分科學家與技術透過 Operation Paperclip 流入美國。
- 部分流入蘇聯。
- 部分流入南美（含[[沈定]]——黑桌介入接走）。

### 1945.08 廣島長崎
- 核武試爆——驚動四族外星。
- 此後外星 UFO 目擊事件爆炸性增長。

## 現代

### 1949 國共內戰 + 國府撤退來台
- 雅典保守派政府從大陸帶走少量[[玄君七章秘經]] 殘篇（含江西龍虎山、四川青城山、北京白雲觀來源）。
- 蔣介石「天命焦慮」催生**雙線並進**戰略：常規軍備 + 神秘路徑。
- [[雅典地區秘史|戊組]] 雛形誕生。

### 1947.07 羅斯威爾事件
- 小灰人飛船墜毀。
- 殘骸 + 活體被美方回收。
- DSI 正式成立的奠基事件。

### 1955 漢斯·施奈德抵台
- 前納粹 SS 軍官帶 Die Glocke + Vril + 分佈式主機（[[沈定]]計劃副本）檔案至雅典地區。
- 換 1500 萬美金 + 餘生庇護。
- [[雅典地區秘史|戊組]] 首次掌握歐洲神秘學一線資料。

### 1954 格瑞達條約
- 艾森豪總統與小灰人代表簽署。
- 條件：小灰人可在美國境內進行有限制的「研究」，交換科技轉移。
- **聯合維穩理事會（UCC）** 同年成立。

### 1961 巴尼希爾外星綁架事件
- 第一個被公開的「綁架案」。
- 開啟 UFO 文化主流化。

### 1962 蘇聯反主流派情報外流至雅典地區
- 蘇聯情報部門內部反主流派透過瑞士銀行家向[[雅典地區秘史|戊組]] 售出檔案。
- 含通古斯真相 + UAP 研究 1947–1960 摘要 + 「南極地理節點」。
- 戊組首次知道地球有外星實體與諸神殘響。

### 1964 中共原子彈試爆
- 蔣介石震怒，下令**桃園計劃**（核武秘密研發）。
- [[雅典地區秘史|戊組]] 雙軌啟動：表面核武 + 暗線神秘力量。

### 1972 內蒙古墜落事件
- 蟲族飛船墜毀於內蒙古。
- 中央調和局正式接觸蟲族。

### 1980s 戰略防禦倡議（星戰計劃）
- 表面：對抗蘇聯核武。
- 實際：部分為對抗蜥蜴人衛星據點。
- DSI 與蜥蜴人關係此時出現裂痕。

### 1988.01 張憲義叛逃 + 桃園計劃終止
- 表面：雅典地區核武計劃失敗，核武原料被美方收繳。
- 實際：[[雅典地區秘史|戊組]] 緊急尋找「核武替代方案」——接洽各國神秘陣營。
- 1989–1992 接洽 DSI、Тень 皆被冷處理。
- **1993 年[[弦機關]] 在台分支主動回應**，戊組接受成為弦機關政府界面，換取黑科技。
- 從此戊組與弦機關**互依共生**。

### 1989 鮑勃·拉扎爾事件
- 美方科學家公開揭發 S-4 基地與反重力研究。
- 影子政府後續以「精神不穩」抹黑——但部分情報已外流。

### 1990s 阿祀那族集體死亡事件
- 阿祀那族五系全滅，僅[[無影]] 為血印系最後一人。
- 真因未明（候選多重，見[[阿祀那族#滅絕]]）。
- **戊組「光復」血脈純化計劃**為候選真因之一——時間吻合度極高。

### 1990s 戊組「光復計劃」啟動
- [[雅典地區秘史|戊組]] 開始追蹤散落在台的[[阿祀那族]] 血脈遺民。
- 戊組**不是滅絕兇手**——是在滅絕之後接管血脈追蹤。

### 1995 周老逝世，陸維中接任戊組組長
- 前戊組組長周老（外省退役上將）臨終指定基層出身的[[陸維中]] 接任。
- 力排眾議的提拔成為陸維中終生信念來源。
- 陸維中接任後整頓戊組，清掉外省世家二代掛名占缺者。

### 1990s 末 宋棠屠村事件
- 雅典地區某偏遠阿祀那族末裔聚居山村被異物屠村。
- 觸發者為童年[[宋棠]]：誤念村中傳家寶**[[亡靈之書]]**（[[玄君七章秘經]] 第三章〈罪〉殘篇）。
- 門局部裂縫，異物滲入屠村，父母爺爺整村死亡。
- [[弦機關]] 緊急收尾，救出唯一倖存者宋棠。
- 戊組**事後才知道**，未能搶到宋棠，從此持續監視。

### 2003 戊組「黑橋計劃」啟動
- [[雅典地區秘史|戊組]] 秘密與[[降臨神會]] 建立通訊管道——**兩面下注**。
- 副組長層級主持，[[陸維中]] 知情但不參與，保留可否認性。

### 2003 戊組與沈定首次正式對等對話
- [[陸維中]] 與[[沈定]] 第一次直接對話——戊組史上第一次。
- 雙方確認互依共生 + 互相提防的長期格局。

### 1997 鳳凰城光點事件
- 大規模 UFO 集體目擊，數千人證實。
- 影子政府首次無法完全封鎖——進入「淡化」階段。

### 2001.09.11 911 事件
- 表面：恐怖攻擊。
- 影子層：DSI 與沙暮的某次失敗合作（具體真相**待作者拍板**）。
- 後續：美國國安體制全面擴張——影子政府控制力大增。

### 2008 金融海嘯
- 表面：次貸危機。
- 影子層：暗倫敦俱樂部第一次測試「全球金融可控崩潰」。

### 2013 史諾登洩密
- NSA 全球監控曝光——影子層的「資訊壟斷」機制首次大規模洩漏。
- DSI 內部對「資訊管控策略」進行重組。

### 2017.12 紐約時報 UAP 報導
- 國防部正式承認 UAP 影片真實。
- 影子政府開始**主動緩釋**外星訊息——「先曝光先定義」策略。

### 2019–2021 COVID-19
- 表面：疫情。
- 影子層：**未明**——可能為某派系生物實驗失控，可能為主動演習。
- 確定影響：全球控制工具大幅升級（疫苗護照、數位身分、央行數位貨幣加速）。

### 2020.04 美國海軍公開三段 UAP 影片
- UAP 訊息曝光的里程碑。
- 各陣營進入「外星揭密競賽」階段。

### 2022.02 俄烏戰爭
- Тень 對北約的代理人測試。
- 蜥蜴人勢力在戰場上有觀察記錄（已被影子層消音）。

### 2023.07 美國國會 UAP 聽證會
- David Grusch 證詞：政府持有非人類飛船 + 「生物殘骸」。
- 主流媒體首次無法忽略——L1 訊息正式公開。

### 2024 AI 大爆發
- GPT 系列 + 各國 AI 競賽。
- 影子層共識：AI 是「終極秩序」的世俗化載體。
- 黑桌與 DSI 在 AI 倫理框架上對撞。

### 2025–現代（本書時間錨點）
- 主角們生活在這個時代。
- 各陣營進入「最後幾年」的戰略部署期。
- [[降臨神會]] 在民間擴張中。
- 弦機關處理頻率上升的[[鏡離]] 事件。
- ⚡ darkfate 分歧點主要從這幾年開始發散。

## 近未來（推測）

### 2026–2030 揭密加速期
- 各陣營預期會在這段期間公開更多 UAP 資訊。
- 第一次「公開的外星接觸」可能發生。

### 2030–2035 終極秩序試圖達成期
- 降臨神會 + 蟲族 + 部分蜥蜴人會嘗試實際推進終極秩序。
- 阻力來自：弦機關 + [[沈定]] + 北歐神族 + 部分黑桌守舊派。

### 2035–2040 大結局期（本書主線）
- 「門」是否被打開的決戰期。
- 五件秘寶會在此期間全部現身。

### 2040+ 後事（darkfate 主場）
- 主時間線：守舊派險勝，門被加固，世界恢復「正常」但已知道真相。
- IF A：⚡ 終極秩序達成，個體性消失。
- IF B：⚡ 門被打開，「罪人」回歸。
- IF C：⚡ 蜥蜴人公開奪權。
- IF D：⚡ 沈定本體失控。
