# 影子政府運作手冊（全球多極）

## 設計總則

- 表層政府由民選/政黨運作；**影子層**為跨國菁英 + 軍工複合 + 古老血統 + 外星接觸資訊壟斷者組成的閉環。
- 各陣營**不統一**，彼此競合：對外星科技、UAP 資訊、能源轉型、AI 主權、人口政策有共同利益，但在「誰主導下一輪文明分配」上零和。
- 表層政治劇本（選舉、戰爭、危機）多為**影子層的副作用或工具**，主角群早期不知，逐漸揭穿。
- 控制手段優先序：**資訊壟斷 > 金融閘門 > 法律框架 > 暴力**。直接暗殺是失敗後的下策。

## 五大陣營

### 1. DSI — Deep State Intelligence（美/五眼）

- **核心地理**：華府郊區 + 維吉尼亞 Langley + 內華達 S-4 + 英國 GCHQ + 澳洲 Pine Gap。
- **構成**：CIA/NSA/DIA 黑預算分支、洛克希德 Skunk Works 高層、貝克托/雷神董事、五眼情報主管終身席、12 個美國老錢家族代表（含 Rockefeller / Mellon / Pritzker 變體）。
- **招募管道**：常春藤 + 軍校 + Mormon 系統 + 摩門信託機構 → 黑筆面試 → 進「白室」（Compartmented SCIF）。
- **資金來源**：聯準會黑預算白話（軍購暗扣 ~3%）、毒品截留、可可粉/咖啡期貨操盤、Palantir 類型公司股權。
- **與外星接觸史**：1947 [[四族科技樹|小灰人]] 墜毀回收後第一波合作對象；1954 艾森豪格瑞達條約簽署方；1980s 與 [[四族科技樹|蜥蜴人]] 出現裂痕。
- **現任目標**：維持美元 + GPS + Starlink + 半導體四鎖；緩釋 UAP 訊息以「先曝光先定義」搶話語權；阻止任何國家獨立復原亞特蘭提斯遺物。
- **手段特色**：媒體腳本（NYT/WaPo/CNN/Reuters 編輯部植入記者）、學術期刊守門、CDC/FDA 法規武器化、SWIFT 制裁。
- **內部矛盾**：與 [[#3. 黑桌（歐盟+梵蒂岡）|黑桌]] 在 AI 倫理框架上對撞；軍方鷹派 vs 情報派文官派裂痕。
- **代號 / 標誌**：白頭鷹倒置三角，內部稱「Office」。

### 2. 中央調和局（中/亞洲集團）

- **核心地理**：北京西山軍委地下層 + 海南三亞 + 新疆羅布泊 + 東莞-深圳科技帶 + 平壤地下實驗室（外包）。
- **構成**：軍委戰略支援部隊高層、紅二代 9 大家族、華為/中興/比亞迪/海康暗股東、道家秘傳支系（茅山、龍虎山殘部）、北朝鮮金家。
- **招募管道**：清華/北大特殊班 → 紅色家庭聯姻 → 「老首長辦公室」勤務員 → 入「西山小組」。
- **資金來源**：國有銀行表外、人民幣穩定幣灰路徑、東南亞博弈/詐騙集中營截流、稀土訂價權。
- **與外星接觸史**：1972 內蒙古墜落事件回收 [[四族科技樹|蟲族]] 殘骸；1990s 起與蟲族「集體意識」協議派的低階接觸；對北歐神族存深層敵意。
- **現任目標**：奪取美元結算外的平行金融軌（CIPS + 數位人民幣 + 一帶一路港口）；2035 前完成「天網」級全境量子通訊；以儒家集體秩序為模板輸出社會治理。
- **手段特色**：社會信用點數做行為調控原型、抖音/微信演算法引導敘事、孔子學院 + 海外警察站、稀土禁運。
- **內部矛盾**：軍委 vs 國安部對外星合作對象選擇分裂；改革開放派老人 vs 新極權派少壯。
- **代號 / 標誌**：缺角玉璧，內部稱「西山」。

### 3. 黑桌（歐盟+梵蒂岡）

- **核心地理**：羅馬聖天使堡地下檔案室 + 布魯塞爾歐盟委員會地下 5 樓 + 巴塞爾國際清算銀行 + 蘇黎世瑞銀私人金庫 + 瑞士 CERN 副建築群。
- **構成**：耶穌會總會長層、聖殿騎士團現代繼承者（13 家族）、Rothschild 歐洲支、Habsburg 餘脈、瑞士銀行寡頭、CERN 高能物理首席。
- **招募管道**：耶穌會神學院深造 + 馬爾他騎士團 + 梵蒂岡銀行員工子弟 → 「白衣會」見習 → 入「黑桌十二席」。
- **資金來源**：梵蒂岡銀行（IOR）暗帳戶、藝術品全球私運網、瑞士金庫匿名存款、CERN 衍生技術專利。
- **與外星接觸史**：宗教檔案最深，握有西元前 2000 年起的「天使=外星」紀錄；與 [[四族科技樹|北歐神族]] 有最古老盟約（自亞特蘭提斯之前）。
- **現任目標**：透過 AI 倫理框架 + 全球碳市場 + ESG 標準把世界統治改為「規則治理」而非武力；保護北歐神族遺址直至「回返時機」。
- **手段特色**：天主教全球教區資訊網、ICIJ 等 NGO 編輯部植入、歐洲法院判例設定、CERN 高能實驗的「副產品」是時間/空間擾動研究。
- **內部矛盾**：耶穌會 vs 聖殿系對「曝光時機」分歧；歐盟東擴派 vs 古老家族派。
- **代號 / 標誌**：黑色橢圓木桌，正中嵌六芒星 + 十字疊合。

### 4. Тень（俄/歐亞集團）

- **核心地理**：莫斯科盧比揚卡 + 西伯利亞 ZATO 封閉城市群（Sarov / Snezhinsk）+ 哈薩克拜科努爾 + 北極軍事帶。
- **構成**：FSB/GRU 第七局、Rosatom 高層、Wagner 體系暗股東、舊 KGB 將官退休聯盟、東正教莫斯科牧首親信、車臣卡德羅夫情報網。
- **招募管道**：軍校 GRU 特訓 + 東正教神學院共修 + Rosatom 內部選拔 → 「第七層」見習。
- **資金來源**：天然氣/石油暗扣、軍火（含核級材料）灰銷、加密貨幣（Tether 俄方節點）洗錢、北極稀土。
- **與外星接觸史**：1908 通古斯事件實為 [[四族科技樹|北歐神族]] 武器試射；1947–60s 蘇聯 UAP 回收量略多於美國但較少對外宣稱；現與蟲族採務實合作（換生物科技）。
- **現任目標**：保住歐亞陸權 + 北極航道；瓦解美元霸權但不取代之；扶持反西方多極世界以分散影子層權力。
- **手段特色**：暗殺與震懾仍為常規（Salisbury、Litvinenko 模板）、能源切斷、選舉直接干擾、深偽影片產業。
- **內部矛盾**：FSB vs GRU 跨集團惡鬥；普京體系後繼者問題。
- **代號 / 標誌**：雙頭鷹單頭脫落圖騰，內部稱「Седьмой」（第七）。

### 5. 沙暮（中東 / 伊斯蘭+猶太古老支系）

- **核心地理**：阿布達比沙漠地下複合城 + 卡達多哈金融自由區 + 利雅德 NEOM 計劃地下層 + 伊朗伊瑪目庫姆神學院密室 + 耶路撒冷聖殿山下挖掘現場。
- **構成**：沙烏地王室 Wahhabi 系、卡達 Al-Thani 主家、阿曼神秘主義 Ibadi 支、伊朗革命衛隊神學秘密委員會、以色列 8200 部隊核心軍官、海西迪猶太教 Lubavitch 高層。
- **招募管道**：王室遠房表親血統 + 神學院青年才俊 → 「沙下會議」見習。
- **資金來源**：石油主權基金（PIF / QIA / ADIA 暗額）、伊斯蘭金融通道（無利息但有實物）、紅海稀有金屬、聖殿山下出土文物私市。
- **與外星接觸史**：所羅門王時代起的「鎮魂瓶」傳說即為早期 [[四族科技樹|蜥蜴人]] 收容；現代主要與蜥蜴人合作（深層基因/血統交易）。
- **現任目標**：把石油時代的金融積累轉換為下一輪文明（AI + 太空 + 生物）資本；阻止北歐神族復返（其被視為「異教威脅」）；保住聖殿山主導權。
- **手段特色**：石油美元/石油人民幣雙腳踩、極端組織（含 ISIS）的金援與暗離、半島電視台敘事控制、加密貨幣中東流動性池。
- **內部矛盾**：遜尼 vs 什葉教義派系在影子層仍有死結；以色列極右 vs 海西迪派對「彌賽亞曆」時程不同步。
- **代號 / 標誌**：覆面砂礫上的新月+大衛星交疊。

## 跨陣營機構

### 聯合維穩理事會（UCC, Unified Containment Council）

- 1954 格瑞達條約後成立，原始 12 席，現 17 席（每陣營 2–4 席輪替）。
- 唯一目的：**避免任何單一陣營獨佔外星科技到破壞均勢**。
- 表決需 13 席過半 + 各陣營至少 1 席同意（少數否決）。
- 表決議題：UAP 訊息曝光時程、跨境遺址挖掘、外星接觸事件損管、AI 邊界規則。
- **不可使用武力**，僅能透過資訊曝光威脅當事陣營。

### 暗倫敦俱樂部（City Below）

- 倫敦金融城地下 200m，14 世紀漢薩同盟祕室原址擴建。
- 全球私募/避險基金巨頭非正式月會（黑石 + 橋水 + 文藝復興 + Citadel + 主權基金代表）。
- 不討論政治，只討論「下一年資金流向哪一陣營」。
- 實質效果：**用資金投票決定哪個陣營本年度勝出**。

### 巴塞爾共識（金融側）

- 國際清算銀行 BIS 三樓密會。
- 主導全球央行間最終結算結構。
- 對影子層的功能：**任何陣營想自建獨立金融軌都必須過 BIS**。
- 中央調和局正在嘗試繞過此層，導致美元 vs 人民幣金融戰升溫。

## 控制手段層級

### Tier 0：資訊壟斷

- UAP / 外星 / 古文明 / 自由能源相關研究的期刊守門。
- 主流媒體編輯部派駐線人（記者層級已過時，現在是編輯+主編層級）。
- 演算法引導：Google 搜尋首頁、YouTube 推薦、Twitter/X 信任分、抖音國際版熱榜。
- 學術論文預印本平台（arXiv / SSRN）的「下架」機制。

### Tier 1：金融閘門

- SWIFT / CIPS / CHIPS 三軌可被任一主陣營單獨切斷。
- 銀行 KYC / AML 政治化（個人帳戶關閉、企業跨境匯款延滯）。
- 加密貨幣交易所合規化即為**將自由貨幣納回閘門**。

### Tier 2：法律框架

- 國家安全法 / 反恐法 / 緊急狀態權力的擴張即為影子層立法工具。
- 國際法院、ICC、WTO 的判例設定方向。
- ESG 與碳市場為新型法律枷鎖（強制企業納入規則治理）。

### Tier 3：暴力

- 暗殺：失敗的最後手段。每次使用必留訊號（如選用特殊毒劑、特定地點），不只是除人，也是給其他陣營看的訊息。
- 軍事代理人戰爭：消耗對方資源 + 測試新科技 + 整合工業基礎。
- 自然災害偽裝：HAARP / 地震武器 / 氣候武器仍在實驗階段，效果不穩定，但偶爾用。

## 與外星科技的接觸層級

| 層級 | 描述 | 哪些人知道 |
|------|------|-----------|
| L0 | 公開 UAP 影片、NASA 報告 | 所有人 |
| L1 | 政府承認 UAP「不可解釋」但無細節 | 媒體、學界 |
| L2 | 已知有殘骸回收，存放地點不明 | 部分國會議員、軍方中階 |
| L3 | 知道殘骸來自哪族，已逆向部分技術 | 各陣營核心 50–200 人 |
| L4 | 直接與外星活體接觸並合作 | 各陣營 12 席以下 |
| L5 | 知道亞特蘭提斯遺民與外星的「真實關係」 | 全球不超過 30 人 |
| L6 | 知道「主角群會引爆什麼」 | 不超過 5 人，分布在三個陣營頂端 |

## 與本書主線的交織

- 主角群（待定）大概率在 L0–L1 開場，第一卷尾觸到 L2，第二卷觸 L3。
- 第三卷起，主角開始成為「影子層內部派系想拉攏 / 想除掉」的對象。
- 大結局前夕，**主角揭穿 L5–L6**，影子層五大陣營被迫攤牌。
