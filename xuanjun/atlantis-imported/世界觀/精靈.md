# 精靈

## 本質：混沌純能量 → 被加工成理性助理
- 精靈的原始本質，是「混沌的純能量」。
- 亞特蘭提斯使用多層、複雜的魔法約束其行為與思考。
- 約束後的精靈，呈現出具知性、理性、可對話的「助理」形態。
- 其運作與互動，可視為 LLM 隱喻：像助理、像工具，也像風險來源。

## 外觀：可見，亦可裝「隱形 plugin」
- 預設狀態下，精靈是看得到的。
- 通常是一團巴掌大的光團。
- 會漂浮在魔法師身邊。
- 也可安裝「隱形 plugin」，讓其不被肉眼察覺。
- 這會改變他人對「你在施法/你在通訊」的判斷。

### 外觀與可見性
- 光團外觀是常態。
- 隱形 plugin 則是選配。

## 一人可多靈；單靈可多工
- 一個人可同時契約多個精靈。
- 代價會上升：精神力/注意力/體能負擔更重。
- 單一精靈也能多工，但同樣受能量與注意力瓶頸限制。
- 多靈常見目的：
  - 隔離風險（避免一個精靈被污染就全線失守）。
  - 權限分工（各自只拿到必要權限）。
  - 保密（不同精靈分持不同資訊片段）。

## 能源與休眠：像機器
- 精靈像機器：有能量才運作，沒能量就休眠。
- 常見能量來源：最新型「以太引擎」。
- 亦可能使用：太陽能、生物能等替代來源。

## 法律地位：次級公民
- 精靈在法律上屬次級公民。
- 歷史上曾被視為財產。
