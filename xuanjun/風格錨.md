# 風格錨 · 玄君書

## 硬規則
- 一句 ≤ 15 字
- 段落 2–3 句，上限 4 句
- 大白話，雅典口語
- 禁形容詞堆砌、文藝腔、AI 式總結句
- 段尾留懸念

## 開幕鉤子（任章必擊中 ≥2）
- 金錢 / 數字
- 懸念 / 異常
- 捷徑 / 秘密
- 死亡 / 危機
- 衝突

## 故事公式
主人公 → 目標 → 挫折 → 反轉 → 結局
意料之外、情理之中。每段必含資訊增量。

## 描寫優先序
動作 / 對白 / 具體感官  >  心理獨白
「他抖了三下手」 > 「他很緊張」

## 抽象恐怖落地
鏡離 / 黑卡顯現必須給：
- 具體感官（聽見什麼、看見什麼錯位、體感）
- 讀值（時間、距離、次數、溫度）
- 因果（誰碰了什麼，下一秒發生什麼）

## 轉折詞
但、然而、卻、沒想到、偏偏

## 後處理
所有章節 / 段落 / 對白 draft → 必過 `/humanizer`
