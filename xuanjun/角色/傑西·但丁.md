# 傑西·但丁

## 一句話定位
26 歲，類馬東石的粗曠平頭男，[[愛麗雅·星羽]] 的親哥，父母雙亡街頭流落時被[[沈定]] 撿回弦機關——**自此非沈定話不聽**。

## 外貌
- 身高體型：180 / 70，**類似馬東石**——肌肉壯實、肩寬背厚。
- 髮型：**平頭**。
- 五官：粗曠、線條硬，笑起來反差萌。
- 衣著：簡單耐操款，常穿圍裙在弦機關廚房裡。

## 個資
- 嗜好：**烹調食物**。
- 最喜歡：**研究美食**。
- 最討厭：**被約束**（自己的妹妹除外）。

## 性格
- 核心：粗中有細，對人粗對食物細。
- 矛盾：天生反骨討厭被約束，**唯獨對妹妹星羽 + 對沈定例外**。
- 觸發點：有人欺負星羽、有人不尊重食物、被約束到忍無可忍。

## 背景

### 父母雙亡與街頭流落
- 與妹妹[[愛麗雅·星羽|星羽]] 是兄妹，父母雙亡（具體原因待補）。
- 兩兄妹流落街頭，但丁負責照顧妹妹。
- 某天**路過的[[沈定]] 發現他們**，帶回弦機關。

### 進弦機關
- 自此**非沈定話不聽**——對沈定有絕對忠誠 + 父親形象投射。
- 沈定親自調教他的戰鬥能力——**力氣極大**，可一拳擊敵不帶血讓人昏死過去。
- 進入 D-38 行動小組。

## 戰鬥特點 / 喜劇梗

- 力氣大到可一拳讓人不帶血昏死。
- **缺點：不能站在正前方**——否則會被誤擊。
- 原因：沈定訓練時曾說「敵人就在你的正前方」——但丁**根深蒂固改不了**，於是任何站在他正前方的人都自動被歸類為「敵人」。
- 隊友戰術調整：所有人從他**側面或後面**指揮，絕不站正前方。
- 喜劇場景：新人不知此事，站他正前方說話，被他一拳打飛——醒來後新人變成「教訓案例」。
- 這個梗反覆在 D-38 任務中製造笑料 + 偶爾的真實事故。

## 烹調愛好

- 弦機關內部公認的「最會做飯的探員」。
- 廚房是他的精神聖地——任何任務後他第一件事就是回廚房做菜。
- 對食材有近乎執著的尊重——浪費食物的人會被他冷視。
- 對[[愛麗雅·星羽|星羽]] 永遠端出她愛的甜口菜。

## 技能 / 配備
- 近戰：力氣級暴力——一拳定勝負。
- 烹調：弦機關級廚神。
- 配備：弦機關制式裝備 + 隨身一把好刀（切菜用，戰鬥時也能切人）。

## 說話習慣
- 句短、直白、有時粗。
- 對妹妹：**完全不同的人**——溫柔到不行。
- 對沈定：稱「沈先生」，垂眼回話。
- 對隊友：直話直說，誰廢話就揶揄誰。
- 口頭禪：「來吃。」「等下做飯。」「敵人在前方。」（後一句已成隊內笑話）

## 人際關係
- [[愛麗雅·星羽|星羽]] — 親妹妹 / 他活著的核心理由。
- [[沈定]] — 救命恩人 / 父親形象 / 絕對忠誠對象。
- [[沈季]] — 同隊好哥們；但丁不知道沈季本體，沈季也樂於保留這份單純友誼。
- [[宋棠]]、[[無影]] — D-38 隊友；但丁對宋棠是「妹子等級保護」（妹妹之外的女性他也會本能照顧）。

## 角色弧線

- **第一卷**：D-38 戰力擔當 + 廚房笑話擔當出場。
- **第二卷**：「正前方」梗反覆 + 某次任務中正前方梗造成真實危機，但丁須面對「沈定教錯了我」的瞬間。
- **第三卷**：大寧山或大結局任務中——但丁可能為了保護星羽或宋棠做出重大選擇。

## 待拍板問題

1. 父母雙亡的具體原因（普通車禍 / 弦機關相關 / 戊組相關）。
2. 「敵人在正前方」梗的真正解除時機——是否在大結局關鍵時刻他終於能站對位置救人。
3. 與沈季成為哥們的契機。
