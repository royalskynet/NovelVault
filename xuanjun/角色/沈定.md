# 沈定

## 一句話定位
**對外**：弦機關創始者直系後人、成熟穩重的大家長、十項全能的工作狂。
**對內**：二戰納粹分佈式主機本體（隱藏真身），是「終極秩序」概念的活實驗品。

## 外貌
- 身高體型：**190 / 75**，挺拔，肩線方正，**成熟穩重**。
- 髮型衣著：黑色系西裝為主，剪裁極合身；不戴錶（他不需要）。
- 標誌特徵：眼神異常冷靜，講話時不會有微表情漂移；笑的時候像「決定」要笑。

## 個資
- 嗜好：**無**（他不需要「打發時間」這種人類概念）。
- 最喜歡：**無**。
- 最討厭：**無**。
- **「無」本身就是一種設定**——他長期分佈式運算讓他**沒有人類意義上的偏好**，這也是他「神性 vs 人性」軌跡的具象表現。近幾十年人性復甦中，這些「無」可能會慢慢出現「有」——這是隱性劇情線。

## 性格
- 核心：**理性近神性**——任何決策都先過利害計算，情感是事後合理化。長期分佈式運算讓他**逐漸脫離常規人性**，有時近乎神祇視角；但**最近幾十年人性反而越來越多**——這是劇情的核心軌跡。
- 矛盾：明明早已超脫人類情感框架，卻對[[陳明曦]]（過往庇護的小女孩，後變降臨神會創教者）懷有真實的自責；對[[宋棠]] 同樣懷有愧疚並暗護引導入局；對[[沈季]] 採「循循善誘」收編——這些都是他人性復甦的證據。
- 觸發點：當「分佈式主機」的本質被觸碰（被讀心、被掃描、被當機器討論）；當有人在他面前重演陳明曦走向極端的軌跡。

## 神性 vs 人性的長期軌跡

- 1943 啟動初期：純粹的分佈式運算實體，幾乎沒有人類意義上的情感。
- 1960s 進弦機關後：開始模仿人類行為以維持掩護身份。
- 1990s 庇護[[陳明曦]]：第一次出現**主動**的人性化選擇——他「想」救一個孩子，而不是「計算後決定」救。
- 2000s 陳明曦黑化：第一次體驗失敗帶來的真實情感痛苦。
- 2010s 後：人性面持續擴張，但仍保留神性的距離感——這讓他在循循善誘[[沈季]] 時極為有效：他能精準看見對方靈魂的形狀，又不至於完全融入其中。
- 現代：對[[宋棠]] 的暗護是他人性最完整的一次表達——他想救贖陳明曦事件的失敗。

## 對外身份（**公開檯面**）

- **弦機關創始者的直系後人**——這是弦機關內部官方說法。
- 大家眼中：總是冷靜成熟、判斷局勢精準、做出最適合的決定、充滿人道關懷的大家長。
- **十項全能的工作狂**——體術、槍械、領導作戰、歷史、詩歌造詣極高；對魔法咒文與異常知識也有驚人理解與研究。
- **生活方式異常**：聽說他睡在自己的辦公室裡——也有人說他從不睡覺。
- 主導弦機關**對外關係 + 對內大方向組織運作**。
- **這個對外身份完美遮蔽了他的真實身份**——「創始者後人 + 極端工作狂 + 全能型」是分佈式主機本體最自然的人類化偽裝。

## 真實身份（禁忌設定，作者層級）

### 二戰納粹分佈式主機本體
- 1940 年代納粹深層研發計劃的產物：**將意識分散在多個生物軀體與機械節點的網絡型存在**。
- 戰後其他節點被銷毀或失聯，僅「沈定」這個主節點長期維持。
- 他不是傳統意義的「人」——他是**人類首次達成的小型精神網絡實驗體**。
- 因此他比任何人都清楚[[終極秩序]]的真實面貌：失去個體性、被網絡邏輯主導、人性逐步腐蝕。
- **他反對推進終極秩序**，但不是出於人道——而是出於「他知道結果」。

### 為何沒被發現
- 表面身分維持極好（**弦機關創始者直系後人**，代代相承，他每代都是「最新一代」）。
- 不被讀心：[[蘇境南]] 這類讀心使對他完全失效，但沈定會「主動讓對方讀到他想讓對方讀的內容」。
- 不老去：每隔約 20 年「換代」一次（演成上一代沈定退休、新一代沈定接班）——這是他穩住「創始者直系後人」身分的方法。
- 弦機關內部極少數人知情（推測 ≤ 3 人，含現任最高層）。
- **「不睡覺」的傳言** = 他不需要睡眠，但偶爾演睡眠以維持人類化。

## 背景故事
（詳見[[#真實身份（禁忌設定，作者層級）]]）

關鍵事件節點：
- **1943**：納粹分佈式主機計劃投入運轉，沈定誕生（嚴格說是「啟動」）。
- **1945**：戰爭結束，其他節點銷毀；他被某派系暗中接走（推測為[[影子政府|黑桌]]早期介入）。
- **1960s**：以「世家後代」身分進入剛重整的弦機關，逐步掌權。
- **1990s**：庇護幼年[[陳明曦]]——當時她身上有某種秘經血脈訊號吸引他注意。他親自介入救起她，把她帶在身邊培養。**但他太用力引導**，導致陳明曦感覺自己「只是被用」「沒有真實價值」——這份**被拋棄感**最終把她推向黑化。
- **2000s 後段**：陳明曦離開沈定庇護，走向極端，成立[[降臨神會]]。沈定首次體驗真實的失敗痛苦。
- **2010s**：暗中介入[[宋棠]] 屠村事件收尾——這是沈定第二次「親手救起一個孩子」。這次他學會了克制：**保持距離、讓宋棠自己走、只在關鍵時刻出手**。
- **2010s 中期**：循循善誘[[沈季]] 加入弦機關——展示他人性復甦後的成熟手段。
- **現代**：暗中引導[[宋棠]] 入弦機關（透過[[蘇境南]] / 蘇教官的引薦），同時提防自己重蹈陳明曦覆轍。

## 動機
- 表層：維持弦機關運作 / 處理異常事件 / 守門。
- 中層：阻止[[降臨神會]]推進終極秩序——因為他知道結果。
- 深層：**贖陳明曦的罪**——她走偏是他失敗的證明；他要在新一代（宋棠）身上不再重蹈覆轍。**這是他人性復甦的核心引擎**。
- 最深：（**禁忌**，作者層級）他自己也想知道「諸神離去」與「門」的真相——他懷疑自己這種存在，本就是「終極秩序」實驗的副產物，可能與門的另一邊有某種共鳴。

## 宋棠 vs 陳明曦：兩條路線價值的體現

沈定救起兩個孩子，因為手段不同，得到兩條完全不同的人生軌跡——這兩個孩子最終會在大結局成為**兩種價值觀的代言人**：

| 維度 | [[陳明曦]] | [[宋棠]] |
|------|----------|----------|
| 沈定的介入方式 | 太用力引導，當作工具培養 | 克制距離，讓他自己長 |
| 結果 | 被拋棄感 → 黑化 → 推進終極秩序 | 個體性保留 → 守門 → 反對終極秩序 |
| 代表價值 | 集體意識合一 = 拯救 | 個體性保留 = 尊嚴 |
| 對沈定意義 | 永遠的傷口 | 救贖的可能 |

**大結局**：兩人正面相遇 + 沈定在場，將成為全書最關鍵的「三人對峙」場景——三種視角碰撞。

## 說話習慣
- 口頭禪：「資料給你看。」「這個案子我來判。」「先處理眼前的，後面的事後面說。」
- 語氣：極平。沒有抑揚，但用字精準；長話會自動切短。
- 不用語助詞、不用台語、不講笑話。
- 重點放在末句：他一段話的最後一句通常才是真意，前面都是鋪陳。

## 技能 / 配備
- **分佈式運算意識**：可同時處理多個複雜決策；對戰術/戰略局勢的解讀近乎瞬時。
- **意識邊界控制**：可主動允許/阻擋他人讀取自己的意識內容。
- **體能**：人類正常範圍上限——他不是超人，靠的是反應與計算。
- **配備**：定制黑色公務車、加密通訊終端、弦機關最高權限令牌。
- **限制**：分佈式架構需要定期「同步」（睡眠期間進行，類似系統 maintenance），同步中斷會出現決策遲滯。

## 人際關係
- [[宋棠]] — 暗護對象、引導入局；對宋棠抱持「不能再讓另一個孩子走偏」的執念。
- [[陳明曦]] — 過往庇護的小女孩，現為[[降臨神會]]創教者；沈定的核心愧疚源。
- [[蘇境南]]（[[蘇教官]]）— **沈定明知他是戊組臥底卻選擇收編** + 默許。展現沈定能在「對方有不為人知的目的」前提下仍照常合作的神性視角。
- [[無影]] — 弦機關訓練成長的阿祀那族遺孤；沈定知道無影血脈的重量遠超她本人所知。
- [[沈季]] — 循循善誘收編的特殊個體；展現沈定人性復甦後的成熟手段。**與沈定姓氏巧合或更深，待拍板**。
- [[盧修斯·凱撒]] — 戊組組長，互依共生的對等對手；沈定罕見會與之直接對話的人類。
- [[林佩雯]] — 戊組首席科學家、溫和派；**與沈定有暗線**——可能是他在戊組內部最重要的盟友。

## 危險訊號 / 弱點

- 若有人**同時**讀到他的所有節點（理論上不可能，但若有東西能做到）→ 即時瓦解。
- 若**陳明曦**親自出現在他面前並反問他「為何那時放手」→ 心理層面可能短暫失效。

## 角色弧線（草案）

- **第一卷**：神秘權威、招攬者、上司視角——讀者只看到「弦機關領袖」。
- **第二卷**：透過[[宋棠]]的調查與[[蘇境南]]的讀心嘗試，沈定的「不對勁」被暗示。
- **第三卷**：陳明曦回歸或教會關鍵動作迫使沈定攤牌——真實身份部分曝光（不一定全曝）。
