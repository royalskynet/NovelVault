# 宋棠

## 一句話定位
弦機關新人特務，前國文教師，大寧山阿祀那族滅村事件唯一倖存者（地面端）。隱藏身份：門的七號鑰匙 / 容器。

## 基本資料
- 年齡：25 歲
- 身高：175cm
- 體重：50kg
- 星座：天蠍
- 喜好：甜食
- 專業背景：歷史
- 童年玩伴：[[無影|易可翱（無影）]]

## 身份疊層

```
前國文教師

```

## 人格
### 顯性人格
- 溫和、正常、能與人維持社交分寸
- 有照顧人、顧全現場氣氛的習慣
- 能當老師、能融入日常，不會一開始就顯露攻擊性

### 隱性人格
- 冰冷、無情、極度理智
- 高智商、低情緒干擾，必要時像工具一樣精準
- 在危機、門、黑卡、記憶碎片被觸發時更容易浮出來

## 能力
### 語言學專業背景
- 弦機關中，兼能解讀與處理異常文字/符文/咒式
- 對黑卡完全免疫（詳見下）

### 隱形與抗干擾能力
- 具備從任何儀器中隱形的能力
- 原理為以米戈異界物質形成的身體遮蔽效果，使常規儀器無法偵測、也無法正確記錄

### 黑卡抗性（特殊）
- 阿祀那血脈抗性 + 童年接觸門外之主意識留下的印記
- 可隨意拿取任何階段的黑卡，不受耳語影響
- 能安全分離黑卡與使用者，最高處理至鏡襲（第三階段）

## 背景故事
### 童年：大寧山事件
- 約 8–10 歲時，因誤觸禁忌引發門局部裂縫，導致全村死亡
- 大寧山阿祀那村全村死亡，僅宋棠與無影倖存
- 弦機關收尾後，[[沈定]] 抹除宋棠相關記憶，帶她離開
- 童年玩伴易可翱（無影）事件前已被族長預見送出，得以倖存

### 記憶缺口
- 宋棠成年後對大寧山事件無完整記憶（弦機關處理）
- 記憶隨劇情推進逐漸覺醒——每次覺醒都帶來新的衝擊

## 動機
- 表層：作為弦機關Ｄ38隊員處置鏡離事件，保護日常
- 中層：追查自己的過去與大寧山的真相
- 深層：在得知容器身份後，選擇讓犧牲最值得（或對此掙扎的弧線）
