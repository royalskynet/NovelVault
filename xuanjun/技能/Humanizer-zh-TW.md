# Humanizer-zh-TW 技能

## 安裝方式

```bash
pip install humanizer-zh-tw
```

## 用途

將 AI 生成文本轉化為更自然、更像人類書寫的繁體中文風格。

## 使用方法

```python
from humanizer_zh_tw import humanize

raw_text = "根據分析結果，我們可以得出以下結論..."
humanized_text = humanize(raw_text)
```

## 與玄君世界觀整合

本技能適用於所有小說寫作任務，確保輸出風格符合 Humanizer-zh-TW 的語感要求。

## SOUL 原則

1. **自然流暢**：避免生硬的 AI 語氣
2. **在地化**：使用台灣慣用表達
3. **情感真摯**：讓文字有溫度
4. **口語化**：適度加入口語連接詞
5. **節奏感**：控制句子長短，避免單調

## 寫作任務時的應用

當執行寫作任務（劇本/段落/對白/續寫/擴寫）時，必須先將草稿透過 Humanizer 轉換，再以轉換後版本輸出。
