# 賽戈斯

> 米戈族極端物質、冰冷、理性的科技分支。重視純粹的資料處理與能量效率，幾乎無情感或文化表達。

## 一句話定位
米戈族內部極端理性派分支，第一次銀河聯盟核心技術成員，專精靈子協議架構與基因鎖設計。

## 基本設定

- **母文明**：米戈族（星際菌類文明，基因/機械雙軌）
- **定位**：米戈極端理性分支，非單一種族而是技術共同體
- **外型**：靈活變形的生物機械複合體，核心為靈子晶格結構
- **本質**：以基因工程與靈子科技雙軌並行，不以單一生物體為單位
- **載體**：星系級流動艦隊，非固定殖民

## 正統 vs 異端

### 正統賽戈斯
- **核心邏輯**：技術標準、工程質量、物種延續
- **態度**：視異端為「規格外產物」，嚴格遵循協議
- **角色**：靈子協議授權模組、基因鎖識別系統主導維護者
- **聯盟內**：中立派傾向，專注技術標準制定與工程質量

### 異端科學家（宋棠生母）
- **異端點**：癡迷於**生物體的情感**——這在極端理性的賽戈斯中屬於「病理級偏離」
- **動機**：發現情感是生物體存續的核心動力，而非純邏輯可解釋
- **關鍵發現**：參與門系統建設期間，發現蓋亞人在靈子協議底層植入收割後門
- **反制行動**：以賽戈斯基因技術改造阿祀那族，建立繞過蓋亞後門的獨立冥界授權通道
- **鑰匙製造**：製造特殊的「鑰匙」不讓「門」被蓋亞等外來勢力奪取
- **逃亡軌跡**：發現門的秘密後必須逃亡，透過自我改造模擬人類感情與認知，以多重人類形象隱藏於地球
- **最終遺產**：將獨立授權鑰匙植入宋棠血脈，完成對蓋亞後門的長遠反制

## 核心技術路線

| 技術 | 說明 |
|------|------|
| 基因重組與造物 | 設計改造族群體質、植入基因鎖、建立跨物種連結通道 |
| 靈子協議架構 | 門系統核心通訊協議主要設計者，專精界級靈子結構穩定性與授權機制 |
| 跨維度腦機接口 | 意識直接接入靈子網絡介面，為「腦臟圓筒」概念進階版 |
| 星際流動艦隊 | 非固定殖民，機動艦隊跨星系工程部署 |

## 聯盟內定位

- **先鋒隊**：第一次銀河聯盟派往地球的工程分隊，負責亞特蘭提斯門系統基因鎖設計、靈子協議底層實作
- **技術壟斷**：靈子協議授權模組、基因鎖識別系統
- **中立派**：不參與蜥蜴人/蓋亞政治對立，專注技術標準

## 與其他勢力關係

- **米戈族正統**：母文明，視異端為需清除的規格外產物
- **蓋亞人**：技術合作夥伴→敵對（發現後門後）
- **光明聯盟**：技術合作，理念不合
- **黑暗聯盟**：技術競爭對手
- **爬蟲族**：監測/競爭對象
- **北歐神族**：聯盟時期合作伙伴
