# 賽戈斯

> 米戈族離散出來的少數研究者群體，本作品虛構的變體——各有愛好的怪咖隱士科學家（geek nerd族群），精通靈子科技但本身不具備靈能。以米戈無感情無道德概念的立場而言，他們是迷戀「情感」與「道德」的變態。

## 一句話定位
米戈族內部因對情感與道德產生研究興趣而分離出來的流放派科學家族群，首領為宋媽（宋棠生母），遭米戈正統一致排斥。

## 基本設定

- **母文明**：米戈族（星際菌類文明，基因/機械雙軌，極端冰冷理性）
- **定位**：米戈流放派分支，非單一種族而是科學家共同體
- **外型**：靈活變形的生物機械複合體，核心為靈子晶格結構
- **本質**：以基因工程與靈子科技雙軌並行，但因對生命與情感產生研究興趣（在母文明中被視為「病態」），偏離純效率導向
- **載體**：星系級流動艦隊，非固定殖民

## 來歷與特色

### 米戈族（正統）
- **核心特徵**：極端理性主義，情感幾乎為零，以純粹邏輯與效率為唯一準則
- **對生命觀**：視生命為可觀測與可操縱的生化系統，無內在價值
- **對異端看法**：視為「不穩定變數」與「情感污染源」，但承認其在理論探索上的價值

### 賽戈斯（流放派）
- **異點**：對**生物體的情感與生命價值**產生研究興趣——這在極端理性的米戈中屬於「病態級偏離」
- **動機**：假設情感是生物體存續的核心動力，嘗試透過基因改造理解或模擬（但自身仍缺乏真實情感能力）
- **地位**：遭米戈正統流放，首領為宋媽
- **關鍵發現**：參與門系統研究期間，發現蓋亞人在靈子協議底層植入收割後門
- **反制行動**：以賽戈斯基因技術在亞特蘭提斯人基因中植入認證，建立繞過蓋亞後門的獨立授權通道
- **鑰匙設定**：將宋棠設定為第七秘寶，作為對蓋亞後門的長遠反制
- **逃亡軌跡**：發現門的秘密後必須逃亡，透過自我改造模擬人類感情與認知，以多重人類形象隱藏於地球
- **最終遺產**：完成阿祀那族基因認證，將宋棠設定為第七秘寶

## 核心技術路線

| 技術 | 說明 |
|------|------|
| 基因重組與造物 | 設計改造族群體質、植入基因鎖、建立跨物種連結通道 |
| 靈子協議架構 | 門系統核心通訊協議主要設計者，專精界級靈子結構穩定性與授權機制 |
| 跨維度腦機接口 | 意識直接接入靈子網絡介面，為「腦臟圓筒」概念進階版 |
| 星際流動艦隊 | 非固定殖民，機動艦隊跨星系工程部署 |

## 聯盟內定位（歷史性）

- **流放派**：第一次銀河聯盟時期，賽戈斯作為米戈流放派參與門系統研究
  - 正統米戈負責純技術實現與效率優化
  - 賽戈斯貢獻靈子協議的情感相容性研究與授權機制創新
- **技術壟斷**：靈子協議授權模組、基因鎖識別系統（與米戈共同開發）
- **立場**：不參與蜥蜴人/蓋亞政治對立，專注技術標準（但賽戈斯更關注倫理含義）

## 與其他勢力關係

- **米戈族正統**：母文明，視賽戈斯為需監控的規格外產物，遭流放後不主動清除除非危害核心協議
- **蓋亞人**：技術合作夥伴→敵對（發現後門後）
- **光明聯盟**：技術合作，理念不合
- **黑暗聯盟**：技術競爭對手
- **爬蟲族**：監測/競爭對象
- **北歐神族**：聯盟時期合作伙伴
