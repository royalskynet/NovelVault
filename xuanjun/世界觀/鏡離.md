# 鏡離

> **鏡離 = 使用黑卡越來越上癮、身心被逐級污染的進程**。由弦機關發現並命名，本質為**黑卡五階段寄生在使用者身心上的具象化投射**——隨著使用者在特定區域長期累積使用，其精神頻率逐漸與蓋亞頻率同步，導致周圍物理/時間常數被蓋亞法則局部覆蓋。

## 本質：五階段寄生進程的環境投射

| 黑卡階段 | 使用者狀態 | 鏡離環境表現 |
|---------|----------|------------|
| **鏡離（第 1 階段，100%）** | 初次接觸，極度上癮、渴望再用 | 區域時間感模糊、微弱迷向感 |
| **鏡像（第 2 階段，80%）** | 精神依賴形成，拒絕分離 | 周圍人情緒同步、夢境重疊 |
| **鏡襲（第 3 階段，60%）** | 身體異變啟動、意志被侵蝕 | 物理法則局部失效、普通人心靈凍結 |
| **鏡隱（第 4 階段，20%）** | 偽裝正常、實則深度同化 | 區域現實扭曲、蓋亞頻率成主導 |
| **鏡身（第 5 階段，0%）** | 完全成為蓋亞節點、失去自我 | **鏡域**——大範圍現實崩塌、物理規則垮塌 |

- **根源**：使用者自身的黑卡寄生進度 → 精神頻率輻射 → 環境鏡離
- **非傳染病**：鏡離不會「傳染」給非使用者，是**使用者頻率投射**覆蓋區域
- **與門無關**：純粹黑卡/蓋亞權柄在物質層的侵蝕前端

## 使用者視角的「上癮機制」

- **初期**：使用黑卡獲得願望實現 → 多巴胺/靈子獎勵雙重強化
- **中期**：不使用會出現戒斷（精神痛苦、幻覺、身體疼痛） → 必須持續用卡維持
- **後期**：使用者**誠實相信**自己在行善、拯救他人——蓋亞頻率重寫其價值觀
- **終點**：鏡身階段，使用者不再是「人」，是蓋亞母體在現世的分身節點

## 心靈效應（環境受影響者）

- **普通人**：心靈凍結暫停，無法思考與行動，時間感消失——被動捲入使用者頻率場
- **強大心靈/異能者**：可抵抗，甚至從中獲得直覺/啟發（蓋亞頻率副作用）
- **關鍵**：一般人凍結 = 接近被蓋亞同化的前兆；意志強大者能短暫抵抗並觀測真相

## 弦機關的應對邊界

| 階段 | 弦機關能力 | 宋棠必要性 |
|------|----------|----------|
| 粗淺（鏡離/鏡像） | 可檢測、隔離、物理銷毀卡片、封印區域 | 不需 |
| 中等（鏡襲初期） | 團隊級應對、高風險、特務易被污染 | 開始需協助 |
| 深厚（鏡襲/鏡隱） | **束手無策**，黑科技失效、只能延遲 | **必須介入** |
| 鏡域（鏡身） | 全員撤退、封鎖資訊 | **專責處理** |

- **人員消耗**：每場深度鏡離處理都消耗特務（長期接觸逐漸被污染）
- **宋棠唯一解**：三重抗性（阿祀那血脈 + 賽戈斯異端鑰匙 + 童年門外之主印記），可安全處理至鏡襲

## 與終極秩序/蓋亞計畫的關係

- **非前兆、是實施展現**：鏡離不是終極秩序的預兆，是**蓋亞同化計畫正在執行的證據**
- **加速器**：鏡離越廣泛 → 社會越接受「異常」 → 蓋亞「善意」敘事越易被接受
- **弦機關困境**：抑制擴散同時不讓大眾知真相 → 資源永遠不足
