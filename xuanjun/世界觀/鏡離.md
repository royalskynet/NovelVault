# 鏡離

> 由弦機關發現的一種特殊現實異常。本質為**黑卡污染導致的蓋亞頻率投影**——當黑卡使用者在特定區域長期累積使用後，該區域的物理/時間常數被蓋亞法則局部覆蓋，所有附近的普通心靈都會被汙染。

## 本質

- **根源**：黑卡使用 → 蓋亞頻率投影在物理空間 → 局部物理法則扭曲
- **表現**：特定區域時間感消失，普通人心靈凍結暫停
- **與門無關**：是純粹的黑卡污染後果，非門封印擾動
- **與蓋亞有關**：實為蓋亞法則在物質層的侵蝕前端

## 心靈效應

- **普通人**：心靈凍結暫停，無法思考與行動，時間感消失
- **強大心靈**：可抵抗鏡離狀態，甚至從中獲得迷幻藥般的啟發與直覺（蓋亞頻率的副作用）
- **關鍵區分**：一般人心靈凍結 = 接近被蓋亞同化的前兆，意志強大的個體能短暫抵抗

## 污染加速機制

| 汙染層級 | 可見症狀 | 處理難度 |
|---------|---------|---------|
| **粗淺** | 單一使用者、幾小時用量 | 弦機關可處理（隔離、加固封印、清除卡片） |
| **中等** | 多個使用者、數星期的區域污染 | 弦機關團隊級應對，有風險 |
| **深厚** | 完整五階段使用者重疊 | **弦機關束手無策，需宋棠介入** |
| **鏡域** | 大規模區域瞬間凍結、物理規則垮塌 | **弦機關全員撤退，宋棠專責處理** |

## 弦機關的應對

- **粗淺處理**：專門技術檢測鏡離範圍、隔離污染區、加固封印、物理破壞黑卡源頭
- **深度瓶頸**：鏡襲以上汙染的鏡離，弦機關黑科技無法逆轉，只能延遲
- **直到宋棠出現**：唯一能安全處理深層鏡離的人——阿祀那血脈免疫 + 賽戈斯鑰匙 + 門外之主印記
- **人員消耗**：每場深度鏡離處理都會消耗特務（長期接觸會逐漸被汙染）

## 與終極秩序的關係

- **非前兆**：鏡離不是終極秩序的實現，是**蓋亞計畫的實施展現**
- **加速器**：鏡離越廣泛 → 人類越接受「異常」→ 蓋亞「善意」顯現越容易被接受
- **弦機關的挑戰**：抑制鏡離擴散的同時，不讓大眾知道真相 → 人力/資源永遠不足
