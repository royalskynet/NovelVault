# D-38 行動小組

[[弦機關]] 旗下異常事件處理特勤小組，直屬[[沈定]]的「Door事件調查部隊」，但沈定本人僅為掛名主事。主角群所屬單位。

## 編號意義

- **D** = Direct（直屬）/ 也有人說是 Door（門）的縮寫——對外不公開。
- **38** = 弦機關內第 38 號常設特勤小組（同編號架構下還有 D-12、D-27 等其他小組）。
- D-38 在內部評價**極高**——因 [[沈定]] 親自掛名督導，又因近年來主場處理重大鏡離 + 黑卡事件。

## 編制

| 代號 / 名字 | 職能 | 備註 |
|------------|------|------|
| **隊長**：[[無影]]（易可翱） | 戰術指揮 + 近戰主力 | 阿祀那血印系，血脈視覺 |
| **核心**：[[宋棠]] | 後期亡靈法師 + 鏡離辨識 + 抗黑卡 | 大寧山倖存者，結局關鍵 |
| **重火力**：[[傑西·但丁]] | 物理壓制 + 廚房後勤 | 「敵人在正前方」梗 |
| **防禦 / 通訊**：[[愛麗雅·星羽]] | 氣球防禦 + 貓頭鷹魔寵 | 化學工廠事件後守時刁鑽 |
| **情報 / 滲透**：[[沈季]] | 擬態 + 社交 + 凌遲 | 真實本體門那邊擬態生物 |
| **教官**：[[蘇境南]]（[[蘇教官]]）| 訓練 + 讀心 | 戊組鏡子計劃臥底，沈定知情 |

## 任務範圍

- **鏡離回收**：弦機關核心業務，D-38 主場。
- **[[黑卡]] 回收**：救援已被黑卡傷害的個體，主要依賴[[宋棠]] 抗黑卡體質。
- **異常事件損管**：化學工廠類事件、突發污染、外洩。
- **秘經殘篇追查**：戊組以外的民間流通本回收。
- **特殊任務**：[[沈定]] 直派的高度機密任務（多與[[復生之書|門事件]] 相關）。

## 與其他單位的關係

- **弦機關訓練處**：D-38 新進來源；[[蘇境南]] 同時掛訓練處與 D-38 雙職。
- **弦機關高層**：[[沈定]] 直管。
- **戊組**：D-38 在執行某些任務時會與戊組外圍合作——多數情況不知對方真實身份。
