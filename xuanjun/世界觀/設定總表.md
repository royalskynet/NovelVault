# 設定總表

> 星際政治與地球命運。故事設定為現代都市奇幻。

## 核心

- [[第一銀河聯盟]] — 人類種起源秘密、星際價值觀角力
- [[門]] — 聯盟各文明研究的對象，其本質仍是謎團 / 靈魂調度後台
- [[冥界]] / [[阿卡西記憶]] — 比已知文明更古老的未知文明遺產
- [[魔法規則]] — 魔法＝各式各樣的先進科技樹、卡爾達肖夫分級

## 勢力

- [[光明聯盟]] —「合一即自由」，12 光環 / 永恆議會
- [[黑暗聯盟]] — 極致個體主義，物質科技 / 機會主義
- [[蓋亞人]] — 光明聯盟核心巨型文明、門外之主偽裝者、降神會神祇真身
- [[爬蟲族]] — 雙支系：外來種（軍工企業）/ 本地原生種（神話原型）
- [[米戈族]] — 星際菌類文明，基因/機械雙軌
- [[賽戈斯]] — 米戈流放派科學家群體，迷戀情感與道德，首領為宋媽
- [[第一次銀河聯盟]] — 人類種起源 / 多方文明共同研究門系統
- [[北歐神族地下網絡]] — 前聯盟監督者、現地下殘餘
- [[降神會]] — 蓋亞代理人組織 / 教主陳明曦
- [[弦機關]] — 光明聯盟執行臂 / 沈定家族百年領導
- [[鎖律會]] — 古老技術壟斷與文明減速組織
- [[戊組]] — 國土安全正規機構
- [[D-38]] — 主角群外勤小組
