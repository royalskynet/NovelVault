# 戊組溫和派

> [[雅典秘史|戊組]] 內部的「**馬克·安東尼路線繼承者**」群體——主張戊組轉型為國土防衛機關、放棄光復、神秘力量只用於守而非攻。與[[盧修斯·凱撒]] 為首的激進派長期共存且對抗。

## 起源

- 創派者：[[馬克·安東尼]]（周漢宸，戊組前組長，1995 逝世）。
- 起點事件：1994 馬克·安東尼與[[沈定]] 那一夜對談 — 馬克·安東尼首次明確表達「**神秘力量只能用來守，不能用來攻**」。
- 馬克·安東尼臨終留下的「四句遺言」成為溫和派的精神 manifesto（詳見[[馬克·安東尼#馬克·安東尼的「四句遺言」（戊組溫和派的精神 manifesto）]]）。

## 精神 manifesto（四句遺言）

> 1. **「守土，勿復仇。」**（傳自馬克·安東尼父親周樞鈞的最後信）
> 2. **「人才不分籍貫，能保家就是同志。」**
> 3. **「我們的時代過去了。你的時代不要學我們。」**
> 4. **「神秘力量只能用來守，不能用來攻。攻就是回到父輩的迴圈。」**

## 核心人員

### [[林佩雯]]（現代代表）
- 戊組首席科學家，**基層出身雅典本地人**（台南農夫之女、嘉義小學老師之孫）。
- 1998 入戊組（27 歲史丹佛物理博士剛回國），由馬克·安東尼親自看上引入。
- 透過讀馬克·安東尼筆記 + 馬克·安東尼父親信件 + 沈定告知馬克·安東尼臨終對話 → 完整繼承溫和派路線。
- 與沈定有 2017 起的長期暗線——每月會面。
- **大結局關鍵內鬼**：把戊組真實歸宗計劃透露給弦機關。
- 父親 2018 臨終遺言「**妳照顧好雅典這塊地就好**」與馬克·安東尼父親遺言「**守土，勿復仇**」精神呼應——本省 + 外省退役上將兩條線在守土立場上**完美匯流**。

### 其他成員（待補）
- 戊組內估計約 30–40% 成員偏向溫和派。
- 主要分布在：科研層、後勤層、行政層。
- 戰鬥單位多偏激進派——他們直接執行任務，更傾向「動作派」思維。

## 兩派的省籍與立場交錯

**最反諷的設定**：兩派代表的省籍與立場**完全不對稱**：

- **激進派 [[盧修斯·凱撒]]**：**外省二代 + 家族被土改清算** → 想光復復仇。
- **溫和派 [[林佩雯]]**：**本省基層 + 父農母師** → 守土不光復。
- **激進派 [[馬克·安東尼]] 早期** → **溫和派 [[馬克·安東尼]] 晚期**：外省退役上將，從光復派轉為守土派。

這個交錯說明：**省籍不是立場的決定因素**——個人歷程 + 對土地的關係才是。馬克·安東尼遺言「人才不分籍貫」的真意就在這裡。

## 激進派 vs 溫和派的根本分歧

| 議題 | 溫和派 | 激進派（盧修斯·凱撒為首） |
|------|--------|------------------|
| 戊組終極目標 | **守土** | **光復** + 守土 |
| 神秘力量用途 | **僅守** | **守攻並用** |
| 羅馬帝國態度 | 已是另一個地方，**接受並存** | 仍是「必須回去」的地方 |
| 對[[弦機關]] | 視為**真正同盟** | 視為**戰術合作對象** |
| 對[[降臨神會]] | **公開敵對** | **公開敵對 + 黑橋秘密通訊兩面下注** |
| 對[[阿祀那族]] 殘餘血脈 | **保護** | **監視 + 必要時可徵用** |
| 馬克·安東尼遺言 | **完整繼承** | **選擇性解讀**——「守土=任何手段保衛家園」 |

## 兩派共存的現狀

- 表面上戊組是統一機關——盧修斯·凱撒是組長，林佩雯是首席科學家。
- 私下兩派**互不信任但表面合作**。
- 盧修斯·凱撒**有意識地讓溫和派存在**——他知道完全清洗會引起戊組崩潰，也知道林佩雯是少數他真正信任的人。
- 林佩雯**有意識地不挑明對抗**——她在等對的時機。
- 雙方都清楚有一天必須攤牌——這是戊組內部最大的張力。

## 與其他派系

- **[[弦機關]]**：溫和派視為**真正同盟**，而非戰術合作對象。林佩雯與沈定的暗線是這條的具體實踐。
- **[[降臨神會]]**：溫和派堅決反對任何接觸（包含黑橋）；激進派的黑橋計劃是溫和派的紅線。
- **全球影子政府**：溫和派傾向與北歐神族系（黑桌古老派）建立聯繫——他們也是「守舊派」。
- **蜥蜴人影子政府**：雙方都不知對方存在。

## 大結局走向

1. **歸宗計劃啟動前夕**：盧修斯·凱撒強推歸宗，林佩雯不再迴避，把計劃內容洩密給沈定。
2. **戊組內部攤牌**：盧修斯·凱撒知道是林佩雯洩的密——他**沒殺她**，而是把她隔離。
3. **聯軍阻止**：弦機關 + 主角群 + 溫和派內應 → 三方合力阻止歸宗計劃。
4. **戊組表面瓦解**：盧修斯·凱撒「健康因素」退休，戊組對外宣告改組。
5. **林佩雯的位置**：可能被任命為「重組後的某新機關」首長——延續馬克·安東尼路線。
6. **暗線繼續**：戊組看似瓦解，實際低調活動——但溫和派從「弱勢」變「主流」。

## 寫作慣例

- 溫和派場景以「**沉靜 + 重量**」為基調——他們是有信念的人，不是怯懦的人。
- 不寫成「正義派 vs 邪惡派」——盧修斯·凱撒也有真誠的信念，只是路徑不同。
- 林佩雯與盧修斯·凱撒的對手戲應該是**戰友之間的撕裂**，不是敵人之間的對抗。

## 待拍板問題

1. 溫和派其他中堅成員的具體身份。
2. 「西門事件」（2013 戊組造成 7 名平民死亡的測試任務）的細節——可作為某章節回憶。
3. 馬克·安東尼的私人筆記目前藏在哪——盧修斯·凱撒保險箱還是林佩雯也已備份。
4. 大結局後溫和派的具體繼承形式（新機關名稱、規模、職能）。
