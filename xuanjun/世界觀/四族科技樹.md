# 四族科技樹

> 四大核心星際文明的技術路線對標。對應卡爾達肖夫指數 I–III 型，亦即「人類視角的四種魔法體系」。

---

## 對標總表

| 文明 | 卡達肖夫等級 | 核心技術樹 | 魔法表現 | 關鍵特色 |
|------|-------------|-----------|----------|----------|
| **蓋亞人 / 光明聯盟核心** | III 型（銀河級） | 精神/意識操控 | 神蹟、靈能力、集合意識 | 能量幾乎無限（跨世界池）、怕非理性善意 |
| **賽戈斯正統 / 米戈主體** | II–III 型 | 生物/基因塑造 + 靈子認證 | 變形、腦機接口、造物 | 純理性、極高算力、技術標準壟斷 |
| **黑暗聯盟 / 爬蟲族外來種** | I–II 型 | 物質/能量工程 | 科技、超武裝、生化改造 | 高效節能、標準化、依賴外部資源 |
| **爬蟲族本地種 / 北歐神族** | I–II 型 | 意識/夢境錨定 | 神話投射、共享夢境 | 根植地球、抗同化、物質投射弱 |

---

## 詳細技術路線

### 1. 蓋亞人 / 光明聯盟 —— 精神魔法極致（III 型）

| 技術領域 | 具體技術 | 應用/表現 |
|---------|----------|----------|
| **精神網絡架構** | 母體分散式靈子運算集群 | 跨星系即時共識、集合意識構建 |
| **意識同化協議** | 「純粹愛與和平的高等頻率」（腸道菌群代謝物信號） | 篩選同化對象、大規模認知作戰 |
| **現實塑造** | 精神力直接操控物質/能量 | 門外之主投射、念力、預知、療愈 |
| **記憶/身份工程** | 阿卡西記憶讀寫、人格分裂/融合 | 門系統管理、輪迴路由、身份鎖定 |
| **能量獲取** | 跨世界靈魂算力轉化 | **同化無數世界 → 能量幾乎無限** |
| **弱點** | 無法模擬非理性善意/犧牲/愛 | 被宋棠等人類特質識破/反制 |

### 2. 賽戈斯正統 / 米戈主體 —— 基因與靈子工程極致（II–III 型）

| 技術領域 | 具體技術 | 應用/表現 |
|---------|----------|----------|
| **靈子認證協議架構** | 界級靈子結構通訊協議、認證模組 | 門系統核心、身分鎖定、記憶讀寫介面 |
| **基因重組/造物** | 模組化基因拼裝、跨物種連結通道 | 宋媽在亞特蘭提斯人基因中植入認證、變形、生物機械融合 |
| **腦機接口** | 跨維度意識接入靈子網絡（腦臟圓筒進階） | 意識上傳/下載、遠程操控、並行運算 |
| **星際流動艦隊** | 非固定殖民、機動工程部署 | 快速響應、分散風險 |
| **技術標準壟斷** | 基因鎖識別系統、認證驗證協議 | 控制誰能存取門系統、冥界 |
| **弱點** | 極端理性、缺乏情感理解、流放派難容 | 被蓋亞精神滲透、被人類情感邏輯困惑 |

### 3. 黑暗聯盟 / 爬蟲族外來種 —— 物質能量工程極致（I–II 型）

| 技術領域 | 具體技術 | 應用/表現 |
|---------|----------|----------|
| **能源工程** | 戴森球變體、反物質電池、零點能抽取 | 龐大能量池、武器級輸出 |
| **量子運算** | 光子計算、分散式共識網絡 | 高速決策、加密/解密、AI 指揮 |
| **基因強化** | 模組化戰鬥體質、壽命交易商品化 | 超級士兵、精英階級專屬 |
| **武器系統** | 相位導彈、時空干擾彈、認知幹擾病毒 | 精準打擊、領域封鎖、心理戰 |
| **資源掠奪** | 能量牧場模式（榨取人類生命獲精神能量） | 解決無精神能力的短板 |
| **弱點** | 依賴外部能源鏈、無精神防禦 | 被蓋亞精神滲透、被賽戈斯技術滲透 |

### 4. 爬蟲族本地種 / 北歐神族 —— 意識夢境錨定（I–II 型）

| 技術領域 | 具體技術 | 應用/表現 |
|---------|----------|----------|
| **共享夢境網絡** | 意識投射、群體清醒夢、神話構建 | 女媧/麒麟/羽蛇神顯現、文化植入 |
| **意識錨點** | 生物多樣性的意識版穩定器 | 地球生態與意識層耦合、抗外來同化 |
| **夢境通道** | 跨物種/跨時空意識連接 | 與遠古記憶對話、獲取失傳知識 |
| **神話投射** | 集體無意識具象化為現實干涉 | 保護特定區域/族群、影響歷史進程 |
| **弱點** | 物質投射極弱、難以量化/武器化 | 易被忽視、易被物質武力壓制 |

## 人類科技定位

- **現代人類**：I 型早期 → I 型中後期（核能、量子計算萌芽、基因編輯初期）
- **弦機關黑科技**：I–II 型邊緣（逆向工程聯盟技術下放、咒式資安、鏡離檢測）
- **D-38 裝備**：弦機關下放技術 + 宋棠特殊能力輔助
- **終局**：人類若存續，必走向多樹融合（宋棠模式）或被單一樹吞併（蓋亞同化/黑暗聯盟實驗場化）
