# 弦機關

> **性質**：神祕的跨國地下組織，名稱暗指以無形的「弦」維繫人世之常理。
> **真實身份**：**光明聯盟在地球的執行機構**，原本目的為擊敗某個想征服世界的霸權，在那之後則將目光放到星際，繼續保護人類。
> **管理模式**：慣例由負責人沈定的家族領導委員會管理，沈定家族百年來都是十項全能、品德高尚的天才。

## 核心使命

- **對外宣稱**：處理異常事件、守護現世安寧、對抗降神會/黑卡/鏡離
- **真實使命（光明聯盟指派）**：
  1. 以任何代價維持人類的「歲月靜好」——不讓超自然影響改變人類日常生活
  2. 監測並壓制門系統異常（鏡離、門外之主滲透）
  3. 追蹤並清除蓋亞人/降神會在地球的滲透據點
  4. 守護人類個體意識不被光明聯盟「合一」同化（**內部極少數知情者的真實意志**）

## 組織架構

| 層級 | 說明 |
|------|------|
| **領導委員會** | 沈定家族百年世襲領導，對外「創始者直系後人」，對內知曉光明聯盟真身 |
| **最高執行長（沈定）** | 實際決策者，二戰納粹分佈式主機本體，神性 vs 人性軌跡核心 |
| **D-38 行動小組** | 主角群所屬外勤編制，處理一線異常（宋棠、無影、沈季、但丁、星羽、蘇境南） |
| **研究/情報部** | 咒式資安、黑卡分析、門系統監測、異常物收容 |
| **後勤/滲透網** | 滲透各國政府、企業、學術界，提供掩護與情報 |

## 關鍵設定：沈定家族百年領導

- **慣例**：沈定家族百年來都是「十項全能、品德高尚的天才」
- **實際**：沈定 = 二戰納粹分佈式主機本體，每隔約 20 年「換代」一次（演成上一代退休、新一代接班）
- **知情層級**：
  - **極少數核心（≤3 人）**：知曉光明聯盟真身、沈定真實身份、門系統完整秘密
  - **中層幹部**：知曉異常處理、降神會對抗、與戊組/各國情報機構互依
  - **基層特務（含 D-38）**：僅知「守門對抗異常」，不知星際政治全貌

## 歷史淵源

| 時期 | 事件 |
|------|------|
| **二戰末期** | 納粹分佈式主機計劃產出沈定，戰後被某派系（影子政府早期）暗中接走 |
| **1960s** | 以「世家後代」身分進入剛重整的弦機關，逐步掌權 |
| **1990s** | 庇護幼年陳明曦——太用力引導導致其黑化，成沈定核心愧疚 |
| **2000s** | 陳明曦成立降神會，沈定首次體驗真實失敗痛苦 |
| **2010s** | 暗中介入宋棠屠村收尾，學會克制：保持距離、只在關鍵時刻出手 |
| **現代** | 暗中引導宋棠入弦機關（透過蘇境南引薦），提防重蹈陳明曦覆轍 |

## 技術與裝備（黑科技）

- **鏡離檢測/加固技術**：專門技術檢測與控制鏡離範圍，**只能處理粗淺層**，深層污染需宋棠
- **黑卡分析/分離儀器**：可處理至鏡像階段，鏡襲以上需宋棠親自處理
- **咒式資安體系**：防禦精靈入侵、黑咒植入，對抗降神會精神污染
- **加密通訊/滲透網**：跨國情報網絡，滲透各國核心部門
- **異常物收容設施**：深層保險庫收容復生之書副本、黑卡樣本、門系統殘響器物
