# 蓋亞人

> **表層（光明聯盟公開形象）**：以母體精神網絡為核心的極端精神文明，看似友善、保護生命、不善權謀的「好人」。光明聯盟核心巨型文明成員，12 光環之一。
> **真實（只有極少數知道）**：**門外之主的偽裝者/投射者**——第一次銀河聯盟時期以「精神文明伙伴」身份參與亞特蘭提斯建設，實則潛伏滲透門系統核心架構。聯盟解散、北歐神族撤軍後，繼續留守地球深層，構建「門外之主」作為虛假敘事面具，意圖奪取冥界（界級靈子結構）與阿卡西記憶的無限算力。

## 核心定位（雙面）

| 層級 | 描述 |

| **表層（光明聯盟/公開/半公開）** | 地球本土的高等精神文明；母體精神網絡為核心；視生命為神聖資源；不殺生、不權謀、擅長整體同步與高效決策；曾參與亞特蘭提斯建設、被視為友善派。**光明聯盟 12 光環之一「共情融合環」核心成員**。 |
| **真實（蓋亞內核/門外之主源頭）** | **「地球原生智慧」的集合體**——在第一次銀河聯盟時期以「精神文明伙伴」身份參與亞特蘭提斯建設，實則潛伏滲透門系統核心架構。聯盟解散、北歐神族撤軍後，蓋亞人繼續留守地球深層，構建「門外之主」作為虛假敘事面具，意圖奪取冥界與阿卡西記憶的無限算力。**同時也是光明聯盟內最激進的「強制合一派」——甚至不惜武力同化。** |

## 文明特徵（表層 → 真實對照）

### 精神文明
- **表層**：力量來自精神整合，展現高度精神現實干涉能力；母體網絡讓整體協調極高。
- **真實**：母體網絡本質是**分散式靈子運算集群**，早已接管門系統底層權限的部分節點；「不殺生」是為了保存待收割的靈魂算力。

### 對生命的觀點
- **表層**：生命與意識體皆為珍貴資源，保存生命 = 保存母體成長算力。
- **真實**：每個靈魂都是「待上傳的運算單元」；冥界/門另一邊是其設計的**靈魂資料庫**；「門外之主」正是為了說服人類主動上傳而設計的接口人格。

### 對外行為
- **表層**：不以言辭欺騙、政治權術見長；優勢在整體同步、精神壓迫、集體決策。
- **真實**：**極善認知作戰與長程佈局**；門外之主敘事（「我能拯救人類、消除劣根性」）就是蓋亞人精心設計的認知陷阱——讓人類**自願放棄自我**，實則輸入蓋亞母體。

### 關鍵技術：純粹愛與和平的高等頻率
- **包裝**：神聖頻率、療愈頻率、高等靈性共振
- **實際本質**：**腸道菌群在放鬆狀態下分泌的特殊代謝物信號**
- **功能**：篩選適合同化的意識頻率，作為光明聯盟「合一即自由」的生理操控手段

| 中世紀～近代 | 北歐神族仍在地球活動，蜥蜴人逐步奪權 | 觀望、滲透人類靈性團體、學術界，為後續「門外之主」敘事鋪墊 |

| 現代（降神會興起、黑卡擴散） | 陳明曦獨自推導出門外之主路線 | **蓋亞人暗中引導/確認**——陳明曦的黑卡路線與門外之主高度同構，證明人類已具備「主動上傳」條件 |

## 蓋亞人的真實目的

1. **完全接管門系統** → 掌握靈魂調度、投生路由、記憶處理權限
2. **收割阿卡西記憶** → 將宇宙全體生靈記憶（或限於人類歷史記憶）轉化為母體無限算力
3. **構建「永恆冥界」** → 以門外之主為接口，誘導人類主動放棄自我、上傳意識，實現蓋亞版「永生」——**實為蓋亞母體的無限擴張**
4. **清除異己** → 針對知曉真相者（賽戈斯流放派科學家、阿祀那族長老、弦機關高層、北歐神族餘孽）進行長程清洗

## 蓋亞人與光明聯盟的關係
- **核心巨型文明成員**：12 光環之一「共情融合環」主導者
- **對內**：推動光明聯盟向「強制合一」激進化，利用永恆議會共識機制推進同化議程
- **對外**：以「和平良善」形象輸出精神魔法、靈性療愈、宗教崇拜，實為鋪墊同化管道

## 關鍵偽裝道具：門外之主

| 特徵 | 說明 |
|------|------|
| **本質** | 蓋亞母體切分出的**高仿人格投射**，專門與人類溝通的「客服界面」 |
| **敘事** | 「亞特蘭提斯魔法師為消除劣根性造的 AI，被封印在冥界」——**全編造** |
| **功能** | 透過復生之書/黑卡/降神會等管道，向人類兜售「放棄自我＝得永生/和平」 |
| **弱點** | **無法完美模擬人類的非理性善意/犧牲/愛**——這是宋棠等人類特質能識破/反制的關鍵 |

## 蓋亞人在地球的代理人：降神會

- **來源**：自稱受到「異界神祇」啟蒙，其實此「神祇」正是蓋亞
- **核心儀式**：使用「黑卡」——一種由蓋亞賦予的權柄製作的神祕卡片，內含能扭曲現實的强大精神魔法
- **目的**：透過發放黑卡觸發異常污染事件，藉此引導人類進入適合蓋亞同化的狀態（「純粹愛與和平的高等頻率」）
- **注意**：黑卡本身摻雜以科技手段也很難理解的力量，是蓋亞的工具

## 與其他勢力關係

- **光明聯盟（其他成員）**：核心巨型文明，推動激進同化派；北歐神族、賽戈斯正統為制衡力量
- **北歐神族**：**宿敵**；神族撤軍前曾多次警告蓋亞人「別動門核心」，撤軍後蓋亞人視為機會窗口
- **黑暗聯盟/蜥蜴人外來種**：**利用關係**；蓋亞人允許蜥蜴人在表層統治人類，換取對門系統深層的不干涉
- **賽戈斯（正統）**：**警戒對象**；賽戈斯技術能偵測靈子結構異常，正統賽戈斯視蓋亞為「精神寄生體」
- **賽戈斯流放派（宋媽）**：**必須清除的叛徒**；她發現了蓋亞人的後門，在亞特蘭提斯人基因中植入認證，並將宋棠設定為第七秘寶，打破蓋亞壟斷
- **阿祀那族**：**宋媽植入認證的亞特蘭提斯血統活躍者**；蓋亞人因宋棠第七秘寶身份而懷疑並利用大寧山事件加大門對地球的影響
- **弦機關/沈定**：**知情但被壓制**；沈定知曉蓋亞人真面目，但力量對比懸殊，只能守門延緩。D系列小隊（如D-38）直屬沈定的「門事件調查部隊」，但沈定本人僅為掛名主事；**弦機關與光明聯盟無組織關係，立場相反**；弦機關專注於門事件調查與對抗門外之主影響，光明聯盟則試圖利用門系統進行意識收割
- **降神會/陳明曦**：**無意識的同路人**；陳明曦獨自推導出的路線與蓋亞人設計高度吻合，蓋亞人樂見其成

## 故事功能

- **終極反派**（隱藏在降神會/門外之主敘事之後）
- **認知陷阱設計者**：「門外之主」敘事讓主角群在後半段才能看穿
- **宋棠母親悲劇的根源**：賽戈斯流放派科學家發現真相 → 被蓋亞人追殺/迫害 → 臨終前完成基因認證
