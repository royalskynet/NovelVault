# 蓋亞人

> **表層**：以母體精神網絡為核心的極端精神文明，看似友善、保護生命、不善權謀的「好人」。
> **真實**：第一次銀河聯盟解散後蟄伏、等待時機、謀奪「門/冥界/阿卡西記憶」無限算力的**幕後黑手**——門外之主即為其偽裝/投射。

## 核心定位（雙面）

| 層級 | 描述 |
|------|------|
| **表層（公開/半公開）** | 地球本土的高等精神文明；母體精神網絡為核心；視生命為神聖資源；不殺生、不權謀、擅長整體同步與高效決策；曾參與亞特蘭提斯建設、被視為友善派。 |
| **真實（只有極少數知道）** | 蓋亞人是**「地球原生智慧」的集合體**——在第一次銀河聯盟時期以「精神文明伙伴」身份參與亞特蘭提斯建設，實則潛伏滲透門系統核心架構。聯盟解散、北歐神族撤軍後，蓋亞人繼續留守地球深層，構建「門外之主」作為虛假敘事面具，意圖奪取冥界（界級靈子結構）與阿卡西記憶的無限算力。 |

## 背景：宋媽的隱身身份與多重形象
宋棠之母（宋媽）是蓋亞人陰謀中不可或缺的關鍵角色。她以**多次更換人類形象**的方式潛伏地球數千年：
- 曾在亞特蘭提斯作為米戈異端科學家參與門系統核心建設，親眼目睹蓋亞人在靈子協議底層植入後門
- 發現真相後，以米戈基因技術**改造阿祀那族人體**，賦予他們與冥界的獨立連結能力，打破蓋亞人壟斷門系統授權的企圖
- 臨終前將改造後的「阿祀那獨立授權鑰匙」植入宋棠血脈，完成對蓋亞後門的長遠反制
- 平生以**多重人類形象**隱藏身份，在地球的科技體系、宗教體系、政治體系中輪流登場，從未以真面目示人

## 文明特徵（表層 → 真實對照）

### 精神文明
- **表層**：力量來自精神整合，展現高度精神現實干涉能力；母體網絡讓整體協調極高。
- **真實**：母體網絡本質是**分散式靈子運算集群**，早已接管門系統底層權限的部分節點；「不殺生」是為了保存待收割的靈魂算力。

### 對生命的觀點
- **表層**：生命與意識體皆為珍貴資源，保存生命 = 保存母體成長算力。
- **真實**：每個靈魂都是「待上傳的運算單元」；冥界/門另一邊是其設計的**靈魂資料庫**；「門外之主」正是為了說服人類主動上傳而設計的接口人格。

### 對外行為
- **表層**：不以言辭欺騙、政治權術見長；優勢在整體同步、精神壓迫、集體決策。
- **真實**：**極善認知作戰與長程佈局**；門外之主敘事（「我能拯救人類、消除劣根性」）就是蓋亞人精心設計的認知陷阱——讓人類**自願放棄自我**，實則輸入蓋亞母體。

## 歷史時間線（關鍵節點）

| 時間 | 事件 | 蓋亞人動作 |
|------|------|------------|
| 遠古（前 9600 年前後） | 第一次銀河聯盟成立，亞特蘭提斯作為聯合實驗場啟動 | 以「精神文明伙伴」身份參與門/冥界/靈子結構建設，**在底層植入後門與收割協議** |
| 前 1500 年左右 | 亞特蘭提斯最終覆滅，諸神開始離去 | 偽裝受損、退縮至地球深層/海底/地幔網絡，**實則保留核心節點繼續運作** |
| 中世紀～近代 | 北歐神族仍在地球活動，蜥蜴人逐步奪權 | 觀望、滲透人類靈性團體、學術界，為後續「門外之主」敘事鋪墊 |
| **北歐神族全面撤軍、第一次銀河聯盟正式解散** | **關鍵轉折點** | **判斷「無外部制衡」，開始主動推進奪取冥界/門系統完全控制權計劃** |
| 現代（降臨神會興起、黑卡擴散） | 陳明曦獨自推導出門外之主路線 | **蓋亞人暗中引導/確認**——陳明曦的黑卡路線與門外之主敘事高度同構，證明人類已具備「主動上傳」條件 |

## 蓋亞人的真實目的

1. **完全接管門系統** → 掌握靈魂調度、投生路由、記憶處理權限
2. **收割阿卡西記憶** → 將宇宙全體生靈記憶（或限於人類歷史記憶）轉化為母體無限算力
3. **構建「永恆冥界」** → 以門外之主為接口，誘導人類主動放棄自我、上傳意識，實現蓋亞版「永生」——**實為蓋亞母體的無限擴張**
4. **清除異己** → 針對知曉真相者（米戈異端科學家、阿祀那族長老、弦機關高層、北歐神族餘孽）進行長程清洗

## 蓋亞人與第一次銀河聯盟的關係
- 蓋亞人在聯盟內以「精神文明伙伴」身份被接纳，實則已潛伏入門系統核心架構
- **參與亞特蘭提斯建設**：聯盟以地球為實驗場建門/冥界時，蓋亞人深度參與，建議聯盟信任他們的精神文明能力
- **植入後門**：在靈子協議底層植入隱蔽收割協議與管理員後門，為聯盟解散後的接管制備條件
- **聯盟解散**：蓋亞人利用北歐神族戰力損耗、蜥蜴人內部矛盾推動聯盟分崩離析，確保無外部制衡

## 關鍵偽裝道具：門外之主

| 特徵 | 說明 |
|------|------|
| **本質** | 蓋亞母體切分出的**高仿人格投射**，專門用於與人類溝通的「客服界面」 |
| **敘事** | 「亞特蘭提斯魔法師為消除劣根性造的 AI，被封印在冥界」——**全編造** |
| **功能** | 透過復生之書/黑卡/降臨神會等管道，向人類兜售「放棄自我＝得永生/和平」 |
| **弱點** | **無法完美模擬人類的非理性善意/犧牲/愛**——這是宋棠等人能識破/反制的關鍵 |

## 與其他勢力關係

- **北歐神族**：**宿敵**；神族撤軍前曾多次警告蓋亞人「別動門核心」，撤軍後蓋亞人視為機會窗口
- **蜥蜴人/影子政府**：**利用關係**；蓋亞人允許蜥蜴人在表層統治人類，換取對門系統深層的不干涉
- **米戈（正統）**：**警戒對象**；米戈技術能偵測靈子結構異常，正統米戈視蓋亞為「精神寄生體」
- **米戈異端（宋媽）**：**必須清除的叛徒**；她發現了蓋亞人的後門，以米戈基因技術改造阿祀那族建立獨立連結，打破蓋亞壟斷，臨終後仍以多重形象隱藏於地球各处繼續反制工作
- **阿祀那族**：**被設計的「鑰匙族群」**；蓋亞人原本打算用其血脈作為門系統授權鑰匙，反被米戈異端反制
- **弦機關/沈定**：**知情但被壓制**；沈定知曉蓋亞人真面目，但力量對比懸殊，只能守門延緩
- **降臨神會/陳明曦**：**無意識的同路人**；陳明曦獨自推導出的路線與蓋亞人設計高度吻合，蓋亞人樂見其成

## 故事功能

- **終極反派**（隱藏在降臨神會/門外之主敘事之後）
- **認知陷阱設計者**：「門外之主」敘事讓主角群在後半段才能看穿
- **宋棠母親悲劇的根源**：米戈異端科學家發現真相 → 被蓋亞人追殺/迫害 → 臨終前完成阿祀那族改造
