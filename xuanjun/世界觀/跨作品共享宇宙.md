# 跨作品共享宇宙

《玄君書》、《亞特蘭提斯之深海王座》**三部共享同一個宇宙**，從不同視角 / 不同時間線切入。

## 對應關係

|------|------------------|----------------------|----------------------|
| 視角 | **地球內部 / 神秘學側** | **地外 / 科幻側** | **時間線分歧 / 平行 IF** |
| 主場景 | 雅典現代都市 | 跨國 / 海底遺跡 / 太空 | 「壞結局」分支現實 |
| 主線議題 | 守門 vs 終極秩序 | 四族角力 + 影子政府 | 「如果終極秩序真的達成了」/「如果門被打開了」 |
| 設定來源 | [[玄君七章秘經]] | 外星科技、亞特蘭提斯遺民 | 主時間線設定的災難放大版 |
| 主角 | 宋棠 + D-38 探員 | 待定 | 待定（可能是主時間線角色的 IF 版本） |

## 共享元素（三作品都成立）

- **影子政府五大陣營架構**（DSI / 中央調和局 / 黑桌 / Тень / 沙暮）。
- **諸神離去**——三部共同的史前事件。

## 留彈性

- 外星四族（北歐神族 / 小灰人 / 賽戈斯 / 蜥蜴人）能力是否與秘經同源——逐族判定。
- 阿祀那族與亞特蘭提斯遺民的關係——待拍板。

## 寫作邊界

- **xuanjun**：不直接出現四族外星人；不直接出現「IF 版本角色」。需要時用「上層的事」「我們碰不到的那層」暗示。
- **atlantis**：不直接展開玄君七章秘經與門/罪人系統；不直接觸 IF 分支。需要時用「東方某部古經」「某個被封印的存在」模糊指涉。
