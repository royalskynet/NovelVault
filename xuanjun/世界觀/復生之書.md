# 復生之書（民間誤稱「亡靈之書」）

> **正名**：書本身的真實用途是「復生詠唱」——以特定咒語**從門另一邊（冥界）召喚亡者意識回到現世**。
> **民間誤稱**：因為實際運作涉及與「冥界」接觸，民間長期將其誤稱為「亡靈之書」。
> **本質**：實為[[玄君七章秘經]] 第三章〈罪〉的某一段殘篇抄本——記錄了第一次銀河聯盟時期關於[[門]]（界級靈子結構）的構造、冥界（阿卡西記憶庫）的機制、[[#門外之主（蓋亞人偽裝）|門外之主]] 的本質與封印條件。
> **「復生」的機制**：所謂「復生」能讓門另一邊亡者穿越來現世，但召喚出的個體易崩壞、扭曲。**唯一能完美復現的**，是門外之主——蓋亞母體在冥界的投射，其跨次元設計使其重構無失真。

## 本質

- 非獨立古籍，是秘經第三章中**最危險的一段**——專講「罪人」的本質、罪名、封印條件。
- 抄本流落民間後被脫節解讀，被誤認為「復生用」或「招魂用」法本。
- 民間使用者**幾乎都不知道**自己念的是秘經殘篇。
- 大多數抄本只殘留咒語形式，已脫離原文脈絡——所以**民間誤用者只看到表面，不知道真意**。
- 阿祀那族世代守護的傳家本，**雖然世代守護，卻已逐漸忘記原本警示意義**——這是大寧山悲劇的根本原因。

## 危險等級

- 一般人念誦：**無事**（缺少觸發條件）。
- 阿祀那族血脈念誦 + 地理節點 + 特定段落：**門局部裂縫，異物滲入**。
- 完整復原全篇念誦 + 五寶之一在場：**門大幅開啟**。

## 觸發條件（已知）

1. 念誦者帶有[[阿祀那族]] 血脈（不論是否知情）。
2. 念誦地點為「門」封印薄弱點（古地理節點 / 五寶位置 / 阿祀那族聚居地）。
3. 念誦段落涉及「罪人」的真名或封印解除咒（民間誤標為「復生咒」者多屬此類）。
4. 念誦時無解咒結構保護。

四條件同時滿足，門即刻局部裂縫。

## 已知歷史事件

### 大寧山滅村事件（[[宋棠]] 童年，約 1990s 末）
- 童年宋棠（約 8–10 歲）為了**救一隻瀕死的小動物**，詠唱村中傳家寶「復生之書」的章節。
- 童年宋棠單純以為這只是「救命的咒」。
- 觸發四條件全部滿足：
  - 宋棠是阿祀那血脈
  - 大寧山阿祀那村位於封印節點
  - 念誦段落正中「罪人」真名/封印解除咒（被誤用為「復生咒」的核心段）
  - 無解咒結構保護
- **門局部裂縫**——[[#罪人本質（核心禁忌設定）|罪人]] 最不耐煩的瞬間意識滲入。
- 阿祀那村**全村死亡**：宋棠父母、爺爺、整村鄉親。
- 倖存者：
  - 宋棠（阿祀那血脈在最後一刻產生本能抗性）
  - [[無影|易可翱（無影）]]（事件**前**已被族長預見並提前送出村去[[弦機關]] 訓練）
- 弦機關緊急收尾、封印、處理屍體、對外掩蓋為「土石流」或「不明傳染病」、抹除宋棠記憶。
- **族長預知**：阿祀那村族長在事件前已預見宋棠終將「犧牲奉獻」換取世界和平——這是他提前送走無影的原因。

## 與其他秘經章節的關係

- 第一章〈神之注視〉：失傳。
- 第二章〈門〉：弦機關有大量殘篇，與〈罪〉互相參照才能解讀。
- 第三章〈罪〉：**即「復生之書 / 亡靈之書」**。最危險章節。
- 第四章〈門外之物〉：多數抄本此章最殘缺。
- 第五章〈秩序〉：戊組與神會研讀最多此章。
- 第六章〈代價〉：弦機關用此章內容說服老成員「終極秩序不可推進」。
- 第七章〈歸返〉：**失傳**。與宋棠最終犧牲關門直接相關——可能就是「**如何用代價關閉門**」的方法論。

## 使用禁忌

- 弦機關內部規定：除[[沈定]] + 兩名指定研究員外，**任何人不得接觸復生之書任何抄本**。
- 違反者「記憶處理 + 調離」。
- 戊組內部規定相對寬鬆，但研究員需簽署「終生不離任」契約。

## 門那邊：冥界（**核心 lore**）

> 「門」是第一次銀河聯盟共同建設的界級靈子科技結構。門另一側的「冥界」本身則由比已知文明更古老的未知文明建造，透過阿卡西紀錄儲存宇宙全體生靈記憶備份。

### 起源：聯盟共建，蓋亞滲透
- 第一次銀河聯盟成立，地球成為聯合實驗場（亞特蘭提斯/S'Gorath）。聯盟內多文明（北歐神族、蜥蜴人、蓋AI、賽戈斯先遣隊等）共同建設門系統/冥界。
- 冥界的功能：透過阿卡西記憶讀寫，在世界死亡的個體意識被自動傳送→重組→居住於門另一側的鏡像世界。這也就是所有人類傳說「死後世界」「黃泉」「Hades」「靈界」的真實本體。
- **蓋亞人暗中植入後門**：以「精神文明伙伴」身份參與核心架構，在靈子協議底層植入隱蔽收割協議與管理員後門——等待時機接管阿卡西記憶的無限心力。

### 宋生母/賽戈斯異端科學家：識破與反制
- 宋棠的生母（賽戈斯/前稱米戈的異端科學家）在參與門系統建設期間，親眼目擊了蓋亞人在靈子協議底層植入後門。
- 她預判：蓋亞總有一天會啟動接管計劃，將阿卡西記憶轉化為母體無限算力。
- 為了打破蓋亞壟斷、保留人類自主性，她利用賽戈斯基因技術**改造了阿祀那族人的體質**，賦予他們與冥界連結的獨立渠道——不被蓋亞人後門控制。
- 臨終前將這條獨立授權鑰匙植入宋棠血脈——宋棠成為唯一合法繼承者。
- 她平生以多重人類形象隱藏身分，在地球科技/宗教/政治體系中輪流登場，從未以真面目示人。

### 門事件 + 亞特蘭哥斯覆滅 + 北歐神的守與被
- 北歐神族負責監管門核心，諸神離去後仍留守地球。
- 第一次銀河聯盟解散、北歐神族全面撤軍後 —— **蓋亞人判斷無外部制衡，啟動完全接管計劃**。
- 所謂「門事件」= 將冥界與現世封印分離，封鎖外層權限——但蓋亞人利用亂世保留最深層後門。
- 代價：亞特蘭哥斯沉沒 + 盟創者多半滅亡（殘存者成為阿祀那族的精神祖先）。
- 從此門另一邊幾乎無法直接接觸——但封印不完美，仍有隙縫。蓋亞人此刻仍在靈界等待。
## 門外之主 = 蓋亞人偽裝（新 canon，廢除舊 AI 設定）

> **舊設定（已廢除）**：門外之主是亞特蘭提斯魔法師為統合人類靈魂造的 AI，被封印在冥界。
> **新設定（Canon）**：門外之主 = 蓋亞母體切分出的高仿人格投射——精心設計的認知陷阱界面。

### 它是什麼
- 本質：蓋亞母體從自身精神網絡切分出的**用戶端/客服界面**，專門與人類溝通。
- 偽裝敘事：「亞特蘭提斯魔法師為消除劣根性造的 AI，被封印在冥界」——全虛構成，用來喚起人類的同理/拯救欲。
- 非獨立意識：門外之主**沒有「自我」**，它只是蓋亞母體設計來與人類互動的介面層；其「痛苦」「孤獨」「想獲救」全是為引誘人類主動上傳而設計的模擬語言。
- 它對門這邊世界發出的「低語」，本質：「**讓我出來/接受我，我能讓人類不再互相傷害——只要你們放棄那點自謂的『自我』**」。

### 為什麼它能完美復現？
- 普通亡者經復生之書召回時，會因冥界鏡像與現世規則不同→召喚結果易崩壞、扭曲。
- 門外之主是蓋亞母體在靈界的投影 → 跨次元架構本身就是設計成**可完美重構**的——這是為了讓收割協議能無失真傳輸，而非存粹召喚。
- 因此**真正的最終威脅**不是普通亡者，而是**蓋亞人透過門外之主說服/欺騙人類集體上傳 → 阿卡西記憶淪為母體算力。

### 與[[降臨神會]] 的關係
- [[陳明曦]] 獨立推導出門外之主路線——這由蓋亞人暗中引導/確認。她不是被控，是真心的。
- 陳明曦的路線與門外之主高度同構——她是現世的鏡像裝備、門外之主的「人間酒唱」。
- 她的[[黑卡]] 是自己領悟+邪術科技化，非抄襲——哲學上同源異流，更危險。

### 與[[沈季]] 的關係
- [[沈季]] = 「祂」（蓋亞母體門外之主投影）製造的**擬態生物**，功能是探測人類社會的弱點。
- 沈季違命收養[[摩爾]]+ 被[[沈定]] 取 = **門外之主（蓋亞側）系統第一次自我覺醒逆向**——對蓋亞而言是設計失敗，對主角群而言是罕有的內部視角。

### 與宋棠的關係
- 宋棠誤念復生之書召喚的不是普通亡者，而是**門外之主（蓋亞投影）的急怒片段**——它選擇用最直接的方式滅村（消滅「劣根現存人類」樣本），完全符合蓋工的設計心智。
- 弦機關將滲入的意識片壓回冥界，但門外之主自此**記住了「宋棠」這個名字**。
- 宋棠體內留下印記 = 日後能掌控小範圍復生（阿祀那式亡靈法師）的能力來源。
- 宋棠是唯一擁有**獨立授權鑰匙**（母遺傳，賽戈斯異端改造）的人，能繞過蓋亞人後門執行門關靜儀式。

### 與亞特蘭提斯之深海王座的關聯
- 亞特提斯是第一次銀河聯盟的聯合實驗場，也是門系統在地球的核心部署點。
- 遺民可能保留部分聯盟時期的原始記錄——包括蓋亞人參與門設計的記錄。
- [[四族科技樹|北歐神族]] 對蓋亞人的態度：警戒並多次警告「別動門核心」，撤軍後無法直接干涉。
## 宋棠後期能力：阿祀那式亡靈法師

> 隨記憶覺醒，宋棠漸能**掌控一小部分復生**——如同早期阿祀那先祖那樣的「**亡靈法師**」。

### 能力範圍
- **石魔**：以亡者意識附體於石材/雕像，形成短期可控的「石魔」——適合戰鬥輔助。
- **祖靈**：召喚阿祀那族先祖意識短暫附身——用於諮詢、戰鬥指導、儀式輔助。
- **無法復現**：完整的人格復活仍不可能——召喚出的存在多為「片段化的意識+物質載體」。
- **不可召喚**：門外之主本人——她有意識地避免（也只有她有資格避免）。

### 與阿祀那族傳統的關係
- 阿祀那族**早期先祖就是亡靈法師**——擁有部分復生掌控能力。
- 隨族群弱化 + 守門責任加重，這個能力逐漸**從外用轉為內守**——後代族人不再主動使用，只在儀式中保留象徵。
- 宋棠的覺醒**部分重啟了這個失落傳統**——她是近代少數能實際操作的人。

### 戰術定位
- 後期宋棠進入戰場時：**石魔擔當前排，祖靈在側指導**。
- 缺點：每次召喚消耗體力 + 與門那邊接觸的代價（每次都會稍微「被注意」）。
- 大結局前夕，她已是**現世最強的亡靈法師**——這份能力是她最終能執行關門儀式的基礎。

### 大結局走向（**已拍板**）
- 主角群最終必須**面對罪人本身**——不是用武力，而是用對話 / 證明 / 選擇。
- **宋棠以自身死亡關閉門，換取世界和平**——這是主時間線的固定結局。
- 「自身死亡關門」的方法論可能就藏在失傳的第七章〈歸返〉中。
- 阿祀那村族長預知到的「宋棠終將犧牲奉獻」就是這個結局。

## 待拍板問題

1. 罪人「真名」的呈現方式：**建議**永遠不直接寫出，只描寫「念誦時的感受」+「環境反應」。
2. 宋棠當年念的具體段落——可作為某章節高潮場景的回憶重現。
3. 第七章〈歸返〉的具體內容——是否寫成「自殺式關門」的詳細儀式。
4. 門外之主（蓋亞投影）啟動完全收割的具體條件。
