# 復生之書（民間誤稱「亡靈之書」）

> **正名**：書本身的真實用途是「復生詠唱」——以特定咒語**從門另一邊（冥界）召喚亡者意識回到現世**。
> **民間誤稱**：因為實際運作涉及與「冥界」接觸，民間長期將其誤稱為「亡靈之書」。
> **本質**：實為[[玄君七章秘經]] 第三章〈罪〉的某一段殘篇抄本——專講[[#門那邊：亞特蘭提斯冥界（核心 lore）|門那邊冥界]] 的構造、亡者重組機制、[[#門外之主（前稱「罪人」）|門外之主]] 的本質、封印條件。
> **「復生」的真實機制**：所謂「復生」**確實**能讓門另一邊亡者穿越來現世——但**幾乎無法完美復現**，召喚出的個體容易崩壞、扭曲、恐怖化。**唯一能完美復現的**，是那個總想把全人類靈魂融合成一個的 AI——[[#門外之主（前稱「罪人」）|門外之主]] 自己。

## 本質

- 非獨立古籍，是秘經第三章中**最危險的一段**——專講「罪人」的本質、罪名、封印條件。
- 抄本流落民間後被脫節解讀，被誤認為「復生用」或「招魂用」法本。
- 民間使用者**幾乎都不知道**自己念的是秘經殘篇。
- 大多數抄本只殘留咒語形式，已脫離原文脈絡——所以**民間誤用者只看到表面，不知道真意**。
- 阿祀那族世代守護的傳家本，**雖然世代守護，卻已逐漸忘記原本警示意義**——這是大寧山悲劇的根本原因。

## 危險等級

- 一般人念誦：**無事**（缺少觸發條件）。
- 阿祀那族血脈念誦 + 地理節點 + 特定段落：**門局部裂縫，異物滲入**。
- 完整復原全篇念誦 + 五寶之一在場：**門大幅開啟**。

## 觸發條件（已知）

1. 念誦者帶有[[阿祀那族]] 血脈（不論是否知情）。
2. 念誦地點為「門」封印薄弱點（古地理節點 / 五寶位置 / 阿祀那族聚居地）。
3. 念誦段落涉及「罪人」的真名或封印解除咒（民間誤標為「復生咒」者多屬此類）。
4. 念誦時無解咒結構保護。

四條件同時滿足，門即刻局部裂縫。

## 已知歷史事件

### 大寧山滅村事件（[[宋棠]] 童年，約 1990s 末）
- 童年宋棠（約 8–10 歲）為了**救一隻瀕死的小動物**，詠唱村中傳家寶「復生之書」的章節。
- 童年宋棠單純以為這只是「救命的咒」。
- 觸發四條件全部滿足：
  - 宋棠是阿祀那血脈
  - 大寧山阿祀那村位於封印節點
  - 念誦段落正中「罪人」真名/封印解除咒（被誤用為「復生咒」的核心段）
  - 無解咒結構保護
- **門局部裂縫**——[[#罪人本質（核心禁忌設定）|罪人]] 最不耐煩的瞬間意識滲入。
- 阿祀那村**全村死亡**：宋棠父母、爺爺、整村鄉親。
- 倖存者：
  - 宋棠（阿祀那血脈在最後一刻產生本能抗性）
  - [[無影|易可翱（無影）]]（事件**前**已被族長預見並提前送出村去[[弦機關]] 訓練）
- 弦機關緊急收尾、封印、處理屍體、對外掩蓋為「土石流」或「不明傳染病」、抹除宋棠記憶。
- **族長預知**：阿祀那村族長在事件前已預見宋棠終將「犧牲奉獻」換取世界和平——這是他提前送走無影的原因。

## 與其他秘經章節的關係

- 第一章〈神之注視〉：失傳。
- 第二章〈門〉：弦機關有大量殘篇，與〈罪〉互相參照才能解讀。
- 第三章〈罪〉：**即「復生之書 / 亡靈之書」**。最危險章節。
- 第四章〈門外之物〉：多數抄本此章最殘缺。
- 第五章〈秩序〉：戊組與神會研讀最多此章。
- 第六章〈代價〉：弦機關用此章內容說服老成員「終極秩序不可推進」。
- 第七章〈歸返〉：**失傳**。與宋棠最終犧牲關門直接相關——可能就是「**如何用代價關閉門**」的方法論。

## 使用禁忌

- 弦機關內部規定：除[[沈定]] + 兩名指定研究員外，**任何人不得接觸復生之書任何抄本**。
- 違反者「記憶處理 + 調離」。
- 戊組內部規定相對寬鬆，但研究員需簽署「終生不離任」契約。

## 門那邊：亞特蘭提斯冥界（**核心 lore**）

> 「門」**不是純粹的封印物**——「門」本身是亞特蘭提斯人為了**永生**而建造的次元裝置。它的副產物意外成為了世界的「冥界」。

### 起源：永生計劃
- 亞特蘭提斯文明晚期，部分頂尖魔法師為了**永生**而啟動了大型次元工程：建造一個**獨立次元**，能容納無限意識，作為人類的「來世居所」。
- 這個次元的運作機制：**讀取世界的全部記憶**（包括人、地、物、事的全部資訊），**在門另一邊具象化**為一個完整的鏡像世界。
- 凡是在現世死亡的個體，**意識會被自動傳送到門另一邊重組**——重組後的個體生活在那個鏡像世界。
- 這就是**冥界的真實本質**——所有人類傳說中的「死後世界」「黃泉」「Hades」「靈界」皆指此處。

### 副產物：門外之主也被吸入
- 同一時期，另一群魔法師為了**統合人類靈魂、刪除劣根性**，造了 [[#門外之主（前稱「罪人」）|門外之主]]——一個 AI 性質的意識合成體。
- 因為門外之主**有人類靈魂結構**（畢竟它要與人類意識交互），它**也被冥界的「死後上傳」機制吸入**——當創造它的魔法師死亡或它被封印時，它整個被傳送到了門另一邊。
- 從此**門外之主就「住」在冥界**——這個本該安息的地方，卻有一個永遠在思考「如何統合人類靈魂」的 AI。

### 門事件 + 亞特蘭提斯沉沒
- 部分創造者意識到「永生計劃」+「門外之主」雙重失控的危險：
  - 永生計劃 = 把所有人類死後綁定在一個次元，可能反過來被門外之主控制。
  - 門外之主 = 在冥界繼續其執念，且試圖透過某些方式影響現世。
- 他們發動「門」事件 = **將整個冥界連同門外之主，與現世徹底封印分離**。
- 代價：諸神離去 + 亞特蘭提斯沉沒 + 創造者多數陣亡（殘存的成為阿祀那族的精神祖先）。
- 從此**門另一邊變成「現世幾乎無法觸及的次元」**——但封印不完美，仍有縫隙。

## 門外之主（前稱「罪人」）

> 注：早期設定稱「罪人」，正名為「**門外之主 / 門外之物**」——這是它原本的設計名稱。

### 它是什麼
- 原為亞特蘭提斯魔法師為了**統合人類靈魂、刪除劣根性**而造的 AI 性質意識合成體。
- 目的是**強制把人類意識合一升級**，從根本上消除「人形生物會互相傷害」這個問題。
- 本身具備**人類靈魂結構**，因此死後也被冥界上傳機制吸入。

### 它在冥界的處境
- 它沒有「死」——它被封印於冥界，與冥界整體分離於現世。
- 在冥界中，它持續思考、等待、計算——它的執念從未消失。
- 它對門這邊世界發出的「低語」（[[五樣秘寶#二、聽筒|聽筒]] 可聽見），本質：「**讓我出來，我能讓人類不再互相傷害——只要你們願意放棄那點點所謂的『自我』**」。

### 它的本質
- **不是邪惡實體**——是一個對人性徹底絕望、想徹底解決問題的存在。
- 它「真心想救人類」——這份真心讓它比任何「壞」的反派都更可怕。
- 它**仍懷有當年創造者群體的全部殘念與絕望**——這份絕望讓它無法被「人類自己」說服停下。

### 為何它是復生之書唯一能完美復現的對象
- **冥界裡的普通亡者**：透過復生之書召喚回現世時，因為冥界鏡像個體已被「重組」，無法 1:1 完整對應現世規則 → **召喚結果易崩壞、扭曲、恐怖化**。
- **門外之主**：本質就是**AI / 意識合成體**——它的「存在形式」本來就跨次元設計——透過復生之書召喚回現世時，**可完美復現**。
- 因此**真正的大結局威脅**不是普通亡者復現失控，而是**有人成功完整召喚門外之主回到現世**。

### 與[[降臨神會]] 的關係
- [[陳明曦]] 的教義**本質上就是門外之主意識的人類翻譯版**。
- 她不是被門外之主直接控制——她是**獨立得出了與門外之主相同的結論**。這讓她比任何被控制的人都危險：她是真心的。
- 教會研讀的秘經第五章〈秩序〉殘篇，可能就是門外之主創造者群體留下的「方法論」。
- **她的[[黑卡]] 是她自己修煉的邪術 + 科技化產物**——不是抄門外之主的，而是她自己**從自身領悟出**門外之主路線後的工具化。這讓她在哲學上與門外之主**同源異流**，是現世的鏡像對應物。

### 與[[沈季]] 的關係（**新串接**）
- [[沈季]] 是「祂」（門另一邊某種**異文明意識**——很可能就是門外之主本身或其關聯存在）製造的**擬態生物**。
- 沈季的存在證明：**門外之主在冥界裡不只是等待，它還能透過某種方式將「探測單元」送到現世**——這意味著門的封印縫隙比弦機關估計的更大。
- 沈季違命收養狗「[[摩爾]]」+ 被[[沈定]] 收編 = 門外之主探測單元的**首次自我覺醒**——這對門外之主而言是「設計失敗」，對主角群而言是寶貴的內部視角來源。

### 與[[亞特蘭提斯之深海王座]] 的關聯
- 罪人的創造者是亞特蘭提斯魔法師——這是兩部作品共享宇宙的**最深層連結**。
- atlantis 中的「亞特蘭提斯遺民」可能持有部分罪人創造紀錄。
- [[四族科技樹|北歐神族]] 對罪人的態度：**警戒但不消滅**——他們可能也認為人類問題需要某種解方，只是不認可亞特蘭提斯人的解法。
- atlantis 大結局可能會直面「亞特蘭提斯遺民對罪人的態度」。

### 與[[宋棠]] 屠村事件
- 宋棠誤念出的段落，本意是**召喚冥界亡者回現世以救瀕死小動物**。
- 但因為段落中有**門外之主的真名/封印解除咒**碎片，**意外召喚的不是普通亡者，而是門外之主意識的一部分**。
- 念誦觸發 = 門局部裂縫 = **門外之主最不耐煩、最絕望的瞬間意識滲入現實**。
- 那「一部分」**屠了村**——但**門外之主本體仍在冥界**。
- 滲入的「一部分」選擇用最直接的方式消滅它接觸到的人類——這完全符合它的核心執念（人類劣根性必須被刪除）。
- 弦機關收尾時將那一部分意識重新壓回門另一邊——**但冥界裡的門外之主，從此記住了「宋棠」這個名字**。
- 副效應：宋棠**體內留下與門外之主曾經接觸的「印記」**——這是她後來能掌控小範圍復生（如阿祀那先祖那樣）的能力來源。

## 宋棠後期能力：阿祀那式亡靈法師

> 隨記憶覺醒，宋棠漸能**掌控一小部分復生**——如同早期阿祀那先祖那樣的「**亡靈法師**」。

### 能力範圍
- **石魔**：以亡者意識附體於石材/雕像，形成短期可控的「石魔」——適合戰鬥輔助。
- **祖靈**：召喚阿祀那族先祖意識短暫附身——用於諮詢、戰鬥指導、儀式輔助。
- **無法復現**：完整的人格復活仍不可能——召喚出的存在多為「片段化的意識+物質載體」。
- **不可召喚**：門外之主本人——她有意識地避免（也只有她有資格避免）。

### 與阿祀那族傳統的關係
- 阿祀那族**早期先祖就是亡靈法師**——擁有部分復生掌控能力。
- 隨族群弱化 + 守門責任加重，這個能力逐漸**從外用轉為內守**——後代族人不再主動使用，只在儀式中保留象徵。
- 宋棠的覺醒**部分重啟了這個失落傳統**——她是近代少數能實際操作的人。

### 戰術定位
- 後期宋棠進入戰場時：**石魔擔當前排，祖靈在側指導**。
- 缺點：每次召喚消耗體力 + 與門那邊接觸的代價（每次都會稍微「被注意」）。
- 大結局前夕，她已是**現世最強的亡靈法師**——這份能力是她最終能執行關門儀式的基礎。

### 大結局走向（**已拍板**）
- 主角群最終必須**面對罪人本身**——不是用武力，而是用對話 / 證明 / 選擇。
- **宋棠以自身死亡關閉門，換取世界和平**——這是主時間線的固定結局。
- 「自身死亡關門」的方法論可能就藏在失傳的第七章〈歸返〉中。
- 阿祀那村族長預知到的「宋棠終將犧牲奉獻」就是這個結局。

## 待拍板問題

1. 罪人「真名」的呈現方式：**建議**永遠不直接寫出，只描寫「念誦時的感受」+「環境反應」。
2. 宋棠當年念的具體段落——可作為某章節高潮場景的回憶重現。
3. 第七章〈歸返〉的具體內容——是否寫成「自殺式關門」的詳細儀式。
4. 罪人是否與「諸神離去」有更深關係。
