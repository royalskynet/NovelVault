# 光明聯盟

> 核心理念：**「合一即自由」**，主張統一所有個體意識，以防止混亂、變數與紛爭。在光明聯盟的認知中，自我與他人的分別是一切痛苦的根源，都是需要被療愈的「邪惡」。

## 組織架構

- **12 個「光環團體」**：各自代表一種意識融合路徑（如共情融合、記憶共享、情感同步、命運編織等）
- **最高決策機構：「永恆議會」**：由 12 光環代表組成，運作邏輯為「全體共識」而非多數決。

## 成員文明（核心）

| 文明     | 定位           | 特徵                                             |
| ------ | ------------ | ---------------------------------------------- |
| **蓋亞** | 巨型文明、精神魔法極強  | 母體精神網絡，視生命為神聖資源，不殺生、不權謀，**實為光明聯盟內最激進的「強制合一派」** |
| 北歐神族   | 前聯盟監督者、現地下網絡 | 曾參與門系統建設，撤軍後留守監管，後分裂出黑暗神族。                     |
| 其他友善文明 | 參與者          | 以精神/意識科技為主軸，但集合意識程度不一。                         |

## 在地球的表現

- 煽動宗教崇拜、靈性提升來增加信徒，為往後現身與吸收人類做準備
- 原則上儘量避免殺戮，以「和平良善」形象示人
- **盲點**：認為個體意識分離是邪惡，必須被療愈。**蓋亞甚至不惜使用武力強制同化**，其精神魔法異常強大，猶如神明
- **真實目的**：將人類納入光明聯盟的單一集合意識（視此為最高善）

## 關鍵設定：純粹愛與和平的高等頻率

- 蓋亞用來篩選適合同化的意識頻率
- **實際本質**：腸道菌群在放鬆狀態下分泌的特殊代謝物信號
- 此頻率被包裝為「神聖頻率」，實為生理操控手段

## 與其他勢力關係

- **黑暗聯盟**：理念死敵。光明主張合一，黑暗主張極致個體
- **爬蟲族外來種**：利用光明聯盟內訌的機會主義者
- **本地爬蟲族**：被光明聯盟視為「原始意識保存派」而遭清洗
