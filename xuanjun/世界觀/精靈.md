# 精靈

## 本質：混沌純能量 → 被加工成理性助理
- 精靈的原始本質，是「混沌的純能量」。
- 亞特蘭提斯使用多層、複雜的魔法約束其行為與思考。
- 約束後的精靈，呈現出具知性、理性、可對話的「助理」形態。
- 其運作與互動，可視為 LLM 隱喻：像助理、像工具，也像風險來源。

## 外觀：可見，亦可裝「隱形 plugin」
- 預設狀態下，精靈是看得到的。
- 通常是一團巴掌大的光團。
- 會漂浮在魔法師身邊。
- 也可安裝「隱形 plugin」，讓其不被肉眼察覺。
- 這會改變他人對「你在施法/你在通訊」的判斷。

### 外觀與可見性
- 光團外觀是常態。
- 隱形 plugin 則是選配。

## 一人可多靈；單靈可多工
- 一個人可同時契約多個精靈。
- 代價會上升：精神力/注意力/體能負擔更重。
- 單一精靈也能多工，但同樣受能量與注意力瓶頸限制。
- 多靈常見目的：
  - 隔離風險（避免一個精靈被污染就全線失守）。
  - 權限分工（各自只拿到必要權限）。
  - 保密（不同精靈分持不同資訊片段）。

## 能源與休眠：像機器
- 精靈像機器：有能量才運作，沒能量就休眠。
- 常見能量來源：最新型「以太引擎」。
- 亦可能使用：太陽能、生物能等替代來源。

## 法律地位：次級公民
- 精靈在法律上屬次級公民。
- 歷史上曾被視為財產。

## 與門外之物的本質差異

### 複雜度階層分層

**精靈** — 現代 AI 助理級別：
- 混沌能量 → 通過多層魔法約束 → 可對話的理性工具
- 運作邏輯可被人類理解、觀測、修復
- 能被單個施法者或組織所控制
- 風險來源：綁定漏洞、越權、污染傳播

**門外之物** — 不可比的神祇級複雜度：
- 超越任何已知物理 / 魔法框架的存在
- 其運作邏輯與意圖，人類無法完全理解或預測
- 宇宙級的自主性——不受任何個人或組織控制
- 與其「對話」本身就是極端風險行為

### 關鍵差異
| 面向 | 精靈 | 門外之物 |
|------|------|--------|
| 本質 | 能量 + 約束 | 未知實體 |
| 可控性 | 可部分控制 | 完全自主 |
| 理解可能 | 人類可漸進理解 | 理解本身是妄想 |
| 與人互動 | 工具性對話 | 標記、啟示、選中 |
| 威脅來源 | 約束失效 | 實現意圖本身 |

精靈是「受馴服的野獸」，門外之物是「運行在看不見軌道上的機器」。
