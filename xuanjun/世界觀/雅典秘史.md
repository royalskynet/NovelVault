# 雅典秘史：第六影子

> 全球五大影子陣營（[[影子政府|DSI / 中央調和局 / 黑桌 / Тень / 沙暮]]）之外，雅典有一條**幾乎所有人都不知道**的第六暗線——由羅馬帝國內戰後逃亡至雅典的政治派系演化出的本土深層體系。
>
> 它的存在連[[影子政府|聯合維穩理事會 UCC]] 也只有零星耳聞，原因是：**它的規模太小、技術太雜、瘋狂程度太高，主流陣營一度視之為地方異象**——直到它**主動接洽[[弦機關]] 換到黑科技**那一刻起，它就不再是地方異象。

## 起源：羅馬內戰敗退與「帝國合法性焦慮」

- 羅馬共和國末期內戰中，某派政治勢力戰敗，部分領導者與親信逃亡至雅典建立流亡據點。
- 表面國策：**光復羅馬帝國，恢復共和制**。
- 深層驅動：**帝國合法性焦慮**——失去羅馬 = 失去統治正當性。
- 為重建合法性，流亡領袖與少數親信開始**雙線並進**：
  - **線 1：常規軍備**——整合雅典軍事力量、尋求國際盟友。
  - **線 2：超常規路徑**——透過從羅馬帝國帶逃出的**少量玄君密經殘篇** + 雅典古代秘密檔案庫的**神秘學文獻**，秘密研究「超越凡俗的權力之路」。
- 線 2 的執行單位後來演化為「**戊組**」（取「戊」為隱蔽代號，避免身份暴露）。

## 戊組：本土影子機構

### 組織歸屬
- 名義：執政官府機要室直屬研究小組。
- 實際：橫跨**雅典科學研究院**、**雅典軍情局**、**雅典情報局某未公開處**的**虛級單位**。
- 預算來源：**特別費** + **國安預算暗扣** + **部分中央銀行黃金儲備收益**（極隱蔽）。
- 規模：高峰期約 200 人，現在約 80 人。

### 戊組與弦機關的關係（**核心設定**）

**戊組不是弦機關的對立面——戊組是弦機關在台的客戶 / 政府皮 / 本土合作方。**

- 1988 桃園核武計劃被收繳終止後，戊組緊急尋找「核武替代方案」。
- 接洽過 DSI、Тень——皆被冷處理。
- **最終接洽到當時還在重整中的[[弦機關]] 在台分支**，換到第一批「黑科技」。
- 從此**戊組成為弦機關在台運作的政府界面**：
  - 戊組提供：法律豁免、土地與設施、政府資金、人脈、政治掩護。
  - 弦機關提供：神秘技術、培訓、秘經殘篇研究結果、異常事件處理 SOP。
- 表面上「兩個獨立機構」，實際上**互依共生 80% 重疊**。
- 但**雙方核心目標不同**：
  - 弦機關：守門、阻止終極秩序。
  - 戊組：光復羅馬帝國統治 / 恢復帝國秩序。
- 這個目標分歧**是未來危機的核心**——一旦戊組決定為了光復動用「不該動的東西」，弦機關必須抉擇是否反過來對付戊組。

### 核心人員

#### 戊組現任組長：**盧修斯·凱撒**（虛構，51 歲）
- **外省二代，家族山東濟南在 1947 內戰時期遭土改清算**：祖父被當街槍決、祖母與叔輩失蹤、堂兄戰死、祖宅燒毀。
- 父親陸德煊為唯一倖存男丁，羅馬內戰敗退至雅典、終生光復派。
- 童年盧修斯·凱撒在祖父祖母遺照前發誓：「**我這輩子要做完爸爸沒做完的事**」——成為他終生核心驅力。
- 雅典大學歷史系畢業，1988 入雅典國防部某秘密單位，跟隨**馬克·安東尼**身邊學習。
- 1995 馬克·安東尼臨終指定接任戊組組長至今。
- **馬克·安東尼提拔他的真實理由**：不是看省籍（兩人同為外省二代），而是賭他「**會像我一樣從光復派轉為守土派**」——這個賭**半成功半失敗**：陸守土了，但沒放下家族復仇。
- **性格**：
  - 實力派、不擅言詞、講話直、做事狠。
  - 山東腔殘留（私下會洩出）；標準國語為主。
  - 核心信念：**保衛家園 + 完成家族未竟事業**——他自己合二為一了。
- **不擇手段**：為了保衛家園+替家族復仇，他願意動用任何資源，包括看起來邪惡的工具。
- 他**清楚知道弦機關的真實程度**——他是戊組史上第一個跟[[沈定]] 對等對話過的組長。
- **與[[沈定]] 的關係**：互相尊重的對手 / 合作者。沈定知道盧修斯·凱撒早晚會走過頭；盧修斯·凱撒知道沈定遲早會反過來阻止他。彼此都在等那一天。

#### 戊組首席科學家

#### 戊組神秘學顧問

## 神秘手稿來源

戊組能成事的三條稀有資料線：

### 1. 羅馬帝國帶來的密經殘篇
- 羅馬內戰敗退時從**羅馬帝國秘密廟宇**、**帝國檔案庫**搜刮帶走的[[玄君七章秘經]] 殘篇。
- 內容偏第三章〈罪〉與第五章〈秩序〉，缺第一章〈神之注視〉與第七章〈歸返〉。
- **總頁數估計：完整經典約 5%**——全球單一機構持有的第三大集合（僅次於梵蒂岡與莫斯科）。
- 第三章〈罪〉部分篇章**俗稱「亡靈之書」**——是[[宋棠]] 屠村事件的觸發來源。

### 2. 雅典古代秘密文獻
- 雅典古代時期曾有神秘組織進行「神明通道與人類信仰融合研究」——意外接觸到**阿祀那族邊緣文獻**。
- 文獻被雅典官方機構封存，存放於雅典古廟下層密室（一般人甚至不知道有此密室）。
- 近代解密重啟研究——戊組接手。

### 3. 納粹與蘇聯手稿

#### 納粹手稿
- **1955 年**，一名德國前 SS 軍官**漢斯·施奈德（Hans Schneider，化名）**抵達雅典，自稱為**藏鏡人**（戊組內部代號），交付一批 SS 神秘學研究檔案。
- 內容含：
  - **Die Glocke**（鐘）計劃殘卷
  - **Vril 接觸協議**草本
  - **分佈式主機計劃**早期文獻（[[沈定]] 項目的「副本」）
- 換取條件：在雅典安享餘生 + 1500 萬美金。
- 1972 年「病逝」於雅典某隱祕地點——**死因可疑**。

#### 蘇聯手稿
- **1962 年**，蘇聯情報部門內**反主流派**透過第三方（一個瑞士銀行家）秘密兜售檔案。
- 內容含：
  - **通古斯事件**真相報告（北歐神族武器試射）
  - **蘇聯 UAP 研究** 1947–1960 摘要
  - **某個尚未證實的「南極特殊地理節點」報告**

## 桃園計劃：核武 → 神秘的轉軌

### 表面：核武計劃
- **1964 年**，羅馬帝國新政權原子彈試爆。龐培震怒，下令「**桃園計劃**」（虛構名）。
- 雅典科學研究院核能研究所為核心執行單位。
- 1968–1987 間秘密推進，幾度接近成功。
- **1988 年 1 月**，張憲義叛逃美國揭發，計劃被迫終止。**核武原料被美方收繳**。

### 1988 後：核武替代方案 = 弦機關黑科技
- 1988 核武計劃終止後，戊組緊急開會：
  - 美國要的是「雅典別有核武」——他們**沒禁神秘力量**。
  - 戊組首席科學家林佩雯（時任副所長）提案：**接洽全球神秘陣營換技術**。
- 羅馬帝國政權轉變期間 戊組四處接洽，多數被冷處理。
- **1993 年**，弦機關在台分支主動回應——條件：戊組成為弦機關政府界面。
- 戊組接受。從此**戊組成為弦機關的「合法掩護」+ 資金管道 + 政府介面**。
- 戊組從弦機關獲得的「黑科技」首批清單（推測）：
  - 鏡離應對 SOP + 基礎裝備
  - 部分秘經殘篇對照解讀
  - 異常事件損管手冊
  - 黑卡識別基礎技術

## 戊組計劃（**重新整理，刪除舊「分身計劃 II」**）

### 計劃一：「光復」——血脈調查
- 目標：**追蹤散落在台的阿祀那族遺民血脈，掌握有資格使用秘寶/秘經能力的個體**。
- 方法：DNA 資料庫比對（透過戶政系統暗中提取）+ 神秘學筛選。
- **與[[阿祀那族]] 滅絕的關係**：
  - 戊組**不是**滅絕兇手——但戊組在滅絕**之後**接管了血脈追蹤工作。
  - 戊組與[[宋棠]] 屠村事件**事後才得知**——他們沒搶到宋棠（弦機關速度更快）。
- 對[[無影]] 與[[宋棠]] 的監視從這條計劃延伸。

### 計劃二：「黑橋」——對降臨神會的雙面下注（**新設定，取代舊分身 II**）
- **戊組秘密與[[降臨神會]] 建立通訊管道**。
- 名義上：滲透情報。
- 實際上：**兩面下注**——萬一[[玄君七章秘經#終極秩序|終極秩序]] 真的達成，戊組想保有席位。
- 通訊管道由戊組副組長層級的某人直接主持，連盧修斯·凱撒也只有「知情但不參與」的距離。
- **這條通訊管道是戊組未來的死穴**——一旦被弦機關發現，戊組與弦機關的合作即刻終止。
- 對[[陳明曦]] 而言：戊組是「可有可無的本土玩家」，她願意通訊只為了**測試這個玩家有沒有秘寶線索**。

### 計劃三：「鏡子」——本土探員訓練池（**新設定**）
- 戊組建立**本土版鏡離應對特工訓練體系**。
- 訓練畢業生**部分留戊組、部分「移交」給弦機關**。
- 弦機關得到能用的本土探員，戊組得到弦機關內部的「自己人」眼線。
- **[[蘇教官]] = 鏡子計劃資深教官**（已拍板：戊組臥底）。
- **[[蘇境南]] = 鏡子計劃退役** + 後期被沈定相中「逆向收編」（已拍板）。

### 計劃四：「歸宗」——重啟光復
- 戊組真正的終極計劃：**透過神秘力量達成「重奪羅馬帝國統治權」**。
- 路徑（戊組高層的想像）：
  - 用淨器碎片或聽筒（[[五樣秘寶]] 之一）影響羅馬帝國統治層
  - 或用黑橋計劃換來的某種能力**精準打擊**羅馬帝國核心權力
  - 或更瘋狂：**用終器啟動局部「終極秩序」，但僅限於羅馬帝國領地內**——讓羅馬帝國民眾意識統合到「流亡雅典政府的帝國願景」之下
- 連戊組內部，知道完整內容的也不超過 5 人。
- **這是全書的潛在大反派計劃**——比降臨神會更貼近主角群日常。
- 弦機關**不知道完整歸宗計劃**——只知道戊組「有些東西沒告訴他們」。

## 戊組大結局走向

> **看似被擊敗瓦解，實際上低調活動**——黑幕、水太深的感覺。

- 大結局前夕，戊組的歸宗計劃被弦機關 + 主角群識破。
- 表面上：
  - 盧修斯·凱撒「健康因素」退休。
  - 戊組核心成員「轉調」或「退休」。
  - 雅典科研院某所被「重組」。
  - 媒體報導為一場政治改革。
- 實際上：
  - 盧修斯·凱撒轉入更深層的「養老顧問」位置，仍實質指揮。
  - 戊組改名（可能變「丁組」「己組」之類）繼續運作。
  - 80% 設施與資金保留，只是換了招牌。
  - 部分核心成員「死亡」實為轉入完全隱秘的單位。
  - 對外國說：「戊組已不存在」。對內：「我們在等下一個時機」。
- **這條結局線**讓本書收尾**不那麼乾淨**——主角群贏了，但沒贏到底；雅典的深層水永遠抽不乾。

## 與主角群的交集（更新）

### 宋棠
- **不是戊組產物**——是村莊屠村事件倖存者。
- 戊組對宋棠的關注始於 1995 前後（屠村事件後幾年）。
- 戊組目前對宋棠**只監視不行動**——因為他在弦機關羽翼下。

### 蘇境南
- 鏡子計劃退役。
- 退役後被沈定相中「逆向收編」——沈定知道他來歷，但選擇用他。
- 蘇境南本人的立場：尷尬。他知道戊組沒完全放他走，但他也不想再回去。
- 這條張力埋伏到中段：戊組可能會「召喚」他回去執行某次任務。

### 蘇教官
- **戊組鏡子計劃資深教官**。
- 在弦機關訓練的學員裡**有計劃地培養特定人選**——表面忠誠弦機關，實際定期向戊組回報。
- 是宋棠進弦機關的引薦人——這條動作背後有戊組的意圖（推測：戊組想透過弦機關保住宋棠，等他成熟後再考慮搶人）。
- 與蘇境南**可能是親屬**（弟弟、堂兄之類，待作者拍板）。

### 無影
- 阿祀那族最後一人——戊組「光復計劃」最高優先監視目標。
- 戊組目前**只觀察不接觸**——她在弦機關羽翼下。
- 大結局前夕，戊組「歸宗計劃」可能會嘗試強取她血脈（這也是弦機關 vs 戊組攤牌的引線之一）。

### 沈定
- 戊組是「山寨他的人」——戊組握有納粹分佈式主機殘卷副本。
- 沈定**接受**戊組的存在，因為他需要戊組的政府皮。
- 盧修斯·凱撒是沈定史上「最讓他棘手的對手」——一個基層出身、保家衛國、不擇手段的本土實力派，是沈定無法直接拆穿（拆穿就連自己也曝光）的存在。

## 寫作邊界與張力

- 所有機構名（雅典科研院、雅典情報局、執政官府等）均為架空設定，非現實機構。
